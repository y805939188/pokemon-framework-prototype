# 招式学习回归

[教学、重学和遗忘计划](../../../src/framework/rules/learning-actions.ts)是纯计算；[学习操作](../../../src/framework/app/learning-operation.ts)绑定当前成员和答案，在提交前复查身份、状态和内容，不让计划自行进队伍查人、分配实体或写存档。

- 教学资格使用成员精确形态，不借用基础形态的资格表。导师／任意等级表命中时不读蛋招；否则按当前形态的蛋招表判定。缺表是未知；明确空表但无完整注册顺序仍是未知。具备完整顺序时，[前身查询](../../../src/framework/rules/evolution-data.ts#L83-L94)先找指向目标有效形态的边（defaultForm → form → 0）；若有效形态非零且没有匹配边，才找指向形态 0 的边。每轮按注册顺序取第一个合格前身，只读该前身的确切形态的蛋招表，不递归、不合并。只有完整顺序且找不到前身才确认没有前身；第一前身缺表仍是未知。这与借用基础形态的教学资料是两件事。重学不会把整张蛋招表当候选。
- ready 中的成员／库存均为独立副本，已反映库存消耗和机器友好度；effects 中仅统计是尚待应用的增量，宿主不得重复扣物或加友好度。待回答、拒绝或取消没有可安装结果；主动放弃也可得到无变更的 ready，需按招式结果判断是否真学会。
- 普通教学与导师使用规范招式 ID；机器资格、招式与消耗取自内容目录，不由名称推断。TM、HM 不消耗；TR 只有目录允许且确实学会时才扣量，背包和队伍入口规则相同。成功的背包机器教学才增加道具教学统计，包括背包 TM 和 HM；只有背包 TR 按招式 ID 追加首次习得，不清理旧记录中的重复项。队伍入口不增加这两项背包记录。
- 机器满槽替换成功才尝试更新友好度：历史友好度 256 仍允许空槽学习，满槽若超出规则范围则整次拒绝。空槽或未开启旧 PP 保留时，新招式使用完整 PP；启用该选项的机器满槽替换取旧 PP 与新招式最大 PP 的较小值，新招式的 PP 提升值始终归零。独立遗忘允许 HM，但不能删掉最后一招；旧档零招式成员仍可学习。重学沿用通用取消层及空列表处理。
- 用例为 test-learning-actions.cjs、test-learning-operation.cjs 和 test-egg-move-content.cjs；这里只记录规则与事务边界，不是 MZ 菜单测试结果。
