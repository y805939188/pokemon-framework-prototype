# 原生地图事件命令

正规入口为 `scripts/tests/g-native-commands-production.test.cjs`。每个命名场景由独立 worker 准备、执行和验证；当前场景清单和输入见 `scripts/tests/final-production-inputs.json`。父进程同时绑定框架分发、插件、Reactor 和 Showdown，拒绝过期 selector、外部运行时或被改写的输入。

- 通过原生 command357 检查真实注册和按来源、名称及全量解除；命令元数据取自当前实际加载的 world 插件文本。
- 畸形、未知或含访问器的输入要被拒绝，getter 不得执行；记录和随机数前缀不变。
- 原生 terminate 只解除精确的句柄，晚到准备不能伤及新拥有者；替换状态后，新一代的移动指令独立处理。
- 地图传送、伙伴可见性、天气和发起战斗在忙时保留各自拒绝语义以及待处理的转移。野生及训练家战斗的拒绝不得造成提交或清除无关拥有者。
- 条件战斗分别检查野生与训练家参数、元数据、来源、内容、代次、小时及忙时接口。拒绝路径不等于成功开战；本组不证明真实窗口、音频或物理输入表现。
