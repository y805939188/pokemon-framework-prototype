# 消息行数与折行

在 `ShowMessage` 的正文写一个小写 `\l[N]` 指定整条消息的行数。N 必须是正整数且窗口可容纳；例如 `\l[2]第一行\n第二行\n第三行` 在第三行前等待翻页。没有标签时使用原生四行。真实换行、`\n` 与 `<br>` 都占用行数。显示期间的样式、速度和等待跨原生分页保持；分页是清页，不是逐行滚动。

`\\l[2]` 显示字面标签；变量或名字中出现标签也不重复执行。多个行数标签、缺右括号、零、负数、小数、空或超过当前画布的行数，在消息取得所有权前拒绝。保存和读档不受消息布局影响。


ShowMessage 在开始时使用宿主字体测量，宽度取原生内容区减去文字左边距。后续词的累计宽度加 2 严格超过可用宽度时，该词整体移到下一行。前面的空白仍留在原行，连续无空格的中英文即使太宽也不会拆字。想在长句中指定断点，可以写真实换行、`\n` 或 `<br>`。

生成的换行进入原生分页。显式 `\l[N]` 仍决定页容量，内嵌选项仍等正文结束后打开。变量、姓名及转义后的文字只按字面测量。含实际着色、样式、文字速度、等待或显式暂停等控制的正文，以及 RTL 正文，继续使用原有布局。普通 MZ「显示文字」和业务消息延用宿主行为。
