# 地图事件消息

使用 **PS_Management → ShowMessage**。填写中、英文文本和窗口位置；空译保持为空。事件解释器等待当前消息结束。显示中文或英文取决于框架语言。文字按玩家速度显示，按确认或返回不会跳字；遇到暂停点则用确认或返回继续，计时等待不能跳过。

| 输入 | 行为 |
| --- | --- |
| `\\` | 一个字面反斜杠，例如 `\\pn` 显示 `\pn` |
| `\pn`、`\pm` | 框架玩家名、千分位金钱；不读 MZ 队伍金币 |
| `\v[N]` | 当前 MZ 变量的普通数字／字符串值；值作为文字插入 |
| `\n[1]` 至 `\n[8]` | 已有 MZ 角色实例名／数据库默认名（存在时）；不懒建角色，不是框架队伍成员名 |
| `\n`、真实换行、`<br>` | 原生换行 |
| `\l[N]` | 本条显式行数；单个小写标签、正整数且窗口须容纳于当前屏幕。见[行数与原生分页](message-layout.md) |
| `<b>…</b>`、`<i>…</i>` | 嵌套粗体／斜体计数；在本消息中跨原生分页保持，结束恢复原字体状态 |
| `\ts[N]` | 从标签起覆盖本条消息的速度，每字 N/80 秒；`\ts[]` 和 `\ts[0]` 即时。不更改玩家设置。打开／加载完成后开始累计；迟帧可补显到期文字，动画／暂停／等待时间不计为待补文字 |
| `\!`、`\1` | 中间暂停，原生暂停箭头，确认／返回后继续 |
| `\.`、`\|` | 等待 0.25／1 秒 |
| `\wt[N]` | 等待 N/20 秒，然后继续，全文仍需确认 |
| `\wtnp[N]`、`\^` | 定时等待后继续并在全文结束时自动结束／全文自动结束；显式中间暂停仍生效 |
| `\c[N]` | **MZ 色板扩展**：复用宿主色板；不等于 参考引擎的皮肤明暗配色 |

替换值当作字面文本，名字和变量中的反斜杠不会再执行。正文支持按顺序解码 `&lt;`、`&gt;`、`&apos;`、`&quot;`、`&amp;`、`&m;`、`&f;` 一次。未支持的标记会保留为文字。颜色使用 MZ 的色板，不提供参考引擎皮肤或音效标签的全部语义。普通 MZ「显示文字」不会因此获得这些插件标签。

样例 Map005 事件 11 展示标签、等待和确认。参阅[分页与折行](message-layout.md)、[独立选项和内嵌选择](choices.md)、[逐位数量输入](number-input.md)和[文字输入](text-input.md)。
