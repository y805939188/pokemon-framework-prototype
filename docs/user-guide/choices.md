# 事件选项

使用 **PS_Management → ShowChoices**。选择已有 MZ 变量保存结果，后续用原生「条件分歧 → 变量」读取。正文和帮助为各语言单独填写的字面字符串，不执行消息标签。确认返回从 0 起的选项索引。

| 参数 | 作者合同 |
| --- | --- |
| `choicesZh` / `choicesEn` | MZ 字符串数组；显示当前语言的列表，单列、宽度按文字测量、长列表原生滚动／翻页 |
| `helpZh` / `helpEn` | 可选字符串数组。省略、空栏、`null` 或 `[]` 为普通选项；非空数组启用底部帮助窗，默认项及光标变化同步显示同索引帮助；缺项为空，多余项不消费 |
| `defaultIndex` | 0 起默认索引；非空列表要求在列表内；空列表要求 0 |
| `cancelValue` | 整数：正数 N 按 BACK 返回 N−1（即第 N 项编码）；负数原值返回；0 禁止取消。正数取消编码不夹到列表范围 |
| `resultVariableId` | 选择已有 MZ 变量；确认写当前 0 起索引，取消写上述编码。沿原生变量赋值请求地图刷新；数值本身不能总区分确认与取消 |

普通“是/否”可用 `["是","否"]`、默认 0、取消 2；取消返回 1，即“否”。严肃确认可把“否”放第一项并让取消也回到第一项。方向先移动，随后按返回（允许取消时）或确认处理。普通空数组保留可确认/取消的空窗口，不等同于 JSON null。

## 在消息末尾接选择

`ShowMessage` 可包含一个小写 `\ch[变量,取消,选项…]`，例如 `是否继续？\ch[13,2,"是","否"]`。正文结束进入普通选项，不另外执行 `ShowChoices`。确认或取消只写一次。下面是内嵌格式；独立选项不解析这套语法。

| 项目 | 用法 |
| --- | --- |
| 标签 | 每条当前语言正文最多一个小写ch；双反斜杠转义的ch是字面；不从姓名、变量替换值或选项文字再解析ch |
| 字段 | 单行逗号分隔；字段外侧空白去除；普通双引号包裹的字段保留内部文字，可含逗号和右方括号。引号闭合后必须紧接逗号或标签结尾 |
| 变量 | 去引号后的非负十进制安全整数，必须为0或已存在MZ变量ID；0沿宿主原赋值规则不产生有效变量写入 |
| 取消 | 完整带可选正/负号十进制安全整数；普通非数字文本（如no/取消）转0。数字前缀混杂、小数/指数等不在接受语法内，定位报错 |
| 选项 | 至少一个字符串，允许空字符串；默认索引0，不带帮助；文字原样进入现有字面选择呈现，不执行标签或替换 |
| 不接受 | 多个ch、空选项列表、未闭合引号/方括号、引号转义或嵌套语法、字段内换行；拒绝在取得消息所有权之前发生，不吞成正常结果 |

样例 Map005 的事件 12 展示独立选项与帮助，事件 15 展示内嵌选项。
