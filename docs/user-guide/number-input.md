# 逐位输入数量

地图事件使用 **PS_Management → Number / 逐位数量输入**。选择一个已有 MZ 变量作为结果变量，再在「按顺序设置」中添加参数。默认无符号范围 0～99，初值读取结果变量的当前值；正常结束后结果写回该变量，原事件继续，可用 MZ「条件分歧 → 变量」消费。初值读取和结果写入只操作 MZ 变量，不涉及框架存档状态。

## 有序参数

每项通过 MZ 结构编辑器填写操作、值、范围最大值。后者只用于范围操作，其余操作忽略。按列表顺序应用，后设范围／位数覆盖前者。

| 操作 | 值与效果 |
| --- | --- |
| 范围 `range` | 「值」为最小，「范围最大值」为最大；最大小于最小时改成最小；显示位数由当前有效范围最大幅值决定，至少一位 |
| 位数 `digits` | 1～15；切换到位数模式，原始范围为 ±(10^N−1) |
| 允许负号 `negative` | 1 允许，0 禁止；允许时多一个 +/− 符号位。禁止时负的最小、最大各夹到 0；原始负范围仍保留，可再次允许负号 |
| 默认值 `default` | 设初值，同时清除此前显式取消值 |
| 初始值 `initial` | 设初值，保留此前显式取消值 |
| 变量初值 `initialVariable` | 「值」为已有 MZ 变量 ID；读该变量作为初值，保留取消值 |
| 取消值 `cancel` | 设整数取消返回值，不夹到范围；可与合法确认值相同 |

初值在打开前夹到最终有效范围；非数字变量值按 0，数值初值取整数部分。默认值／初始值栏是数值文本，非数值文本按 0。没有显式取消值时，BACK 返回夹限后的初值，编辑过的当前数字不会改变这个默认取消值。例：范围 [3,3]、取消 −71、初始值 99，确认仅能得 3，取消得 −71；把最后一步换为默认值 99，则取消得 3。

全负范围 [−9,−3] 禁止负号时有效范围 [0,0]，初值 −6 得 0；允许负号时初值仍为 −6。两位无符号初值 −12/−123 都得 00；有符号分别 −12/−99。取消值始终独立，不因无符号显示而夹到 0。

## 编辑、出口与宿主生命周期

左／右循环移动位光标，按住重复也循环；上／下循环修改当前位的 0～9，选中符号位时切换 +/−。符号与幅值分开，−00 可继续编辑成负数，确认零仍写数值 0。同轮先移动／编辑，随后 USE（Enter/Z）优先于 BACK（Escape/X）：合法 USE 播决定音、写值并结束；越界 USE 播蜂鸣、保留当前编辑并继续等待，同轮 BACK 不执行；独立 BACK 播取消音、按取消值结束。没有额外取消标记，调用者不能只凭结果值判断是否取消。

使用宿主 `Window_NumberInput` 的绘制、光标、窗口动画、逐位按钮和数字请求，局部适配此入口；使用 `Game_Message` 的忙状态、清除、解释器 `message` 等待及 MZ 变量赋值。地图仍沿现有宿主循环更新，忙时新插件命令停在原命令处等待，其他解释器的普通命令仍可运行。正常出口写变量后清除请求、关闭数字窗、刷新输入，事件继续并恢复地图移动。

启用现有 `ConfigManager.touchUI` 时沿用「减／加／确认」按钮与点击数字选位，并在本入口增加「取消」。取消按钮仅对本次请求可用；结束隐藏并移出按钮布局，原三按钮回到原生回调。打开动画期间和旧请求的触控回调不能结束新请求。原生数字命令 103、原生文本合并 103、插件的消息和选项保留各自行为。



样例：Map005 事件 13 使用 −25 至 25 范围，确认返回所选数值，取消返回 −99，再分支处理。幅值不超过 999999999999999；取消值必须为 JS 安全整数。
