# 野生遭遇：概率回归合同

本页规定统计检验的固定条件；不是每次构建都执行的测试，也不代替逐次随机数和跨步状态的验证。

### 样本、阈值和失败解释

固定20个Bernoulli边际，每项N=100000，总2000000样本；每个样本重置到本项同一条件（尤其宽限/累加器）。家族误报上限α=0.01，m=20，L=ln(2m/α)=8.294049640102028。对于期望p，d=sqrt(2Np(1−p)L)+2L/3；通过计数区间为 `[ceil(Np−d),floor(Np+d)]`。这是独立均匀样本模型下Bernstein尾界+union bound给出的同时容差，不要求20边际互相独立。不能改用另一套Hoeffding容差。

0或1的确定性结果用全量精确断言，不放宽。每项只跑冻结seed首轮作为验收；失败保留seed/条件/调用前缀/原计数，先排模型、实现、输入映射，不重新选seed、不增加样本或放宽容差刷绿。后续诊断重跑另记，不抹首轮。合格表示这些边际未发现分布偏移，不能替代逐次RNG前缀/所有状态/原版等价。

### seed与抽样规范

- 根文本精确ASCII：`PF55-P5/v1/20cells-100000/20261115`。UTF-8 SHA256：`ec8ca372e4176c01ffd809e2e11579a70867ace6ff4537d91faa5238c7276d6b`。
- 每cell ID为上表ASCII P01..P20；各自counter从0开始，使用无符号十进制ASCII且无前导零。block=Node crypto SHA256(UTF8(root)+单字节0+UTF8(ID)+单字节0+ASCII(counter))；counter每block加1。
- 每32byte block按偏移0,4,..28读取8个大端uint32，按顺序消费。random(n)验证安全整数1<=n<=2^32；limit=floor(2^32/n)*n；word>=limit丢弃再取；否则word%n返回。cell间不共享counter或未消费buffer；cell内不按sample重置PRNG，按实际到达调用取数。
- 该测试源独立于产品默认RNG，并有自身固定hash、端序、拒绝边界向量。不得用统计结果倒推p；不得将JS `%n`直接当无偏映射。
- 只有本统计harness宣称各cell有独立派生流；产品若仍共用App RandomPort，只记录/重放各用途顺序，不冒称产品业务流独立。

### 连续步长链

另建独立oracle按遭遇规则逐步更新graceSteps/accumulator，使用同一冻结已给定draw tape，比对每次请求域、结果、计数器、候选及允许门早退。覆盖装图保留accumulator、版本同/异值、repel活动与挡下、战斗/Surf重置。不能将2000000个连续步的总体遭遇率直接对21%作binomial检验；其条件概率随状态变化。
