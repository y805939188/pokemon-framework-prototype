# 物种、学习、成长与成员身份

## 内容身份与获得

使用内容中的物种、形态与稳定个体 ID 保存成员；战斗槽、展示名与当前战斗形态不能代替它们。赠送和捕获必须通过正式接收操作，优先遵守实际队伍与盒子容量。确认前是草稿，不持久扣款、改盒或发放第二份成员。图鉴登记和主体写入的耐久性与之后的观看页面分开；关闭展示不能撤销已完成的获得。参阅[队伍与存档](../maintainers/saves-and-party.md)和[图鉴](../maintainers/pokedex.md)。

## 学习与进化

作者可给物种、形态和 overlay 提供有序 `eggMoves`。缺字段表示未知，不等于明确的空数组；显式空数组不继承基础形态。PBS 非法记录整体拒绝，不能当作空表。教学先用当前形态的导师/等级目录，若须读蛋招则优先自己的非空表；仅在已知空表的分支取登记顺序定义的首个前身。无前身是已知无候选，缺前身表是资料不可用。不要合并整条繁育链，也不要在重学菜单中假造曾经学过的招式。

机器、导师、重新学习和主动忘招分别受自己的父操作与成员身份约束。替换、拒绝学习、技术关闭和正常取消不是同一结果。新招替换不能覆盖受保护的 HM；独立忘招有自己的规则，不能忘掉最后一招。TR 消费、招式、PP 与统计通过一次安装提交；确认时重新检查当前资源与内容。交易进化的收发、归属、序号和后续学习保留在同一草稿，最终只有一次持久替换。展示失败不撤销已安装的主体，也不能重复扣道具。

## 回合间成长

真实成员决定经验和 EV 的领取对象，展示用槽位及 Illusion 的外形不决定归属。等级/努力值变化后，以变化前真实最大 HP 计算差值，保持倒下状态的默认政策。永久招式、PP 和永久形态分别结算，Transform 等临时复制槽不能写回。成长后的请求需要刷新，再允许选择下回合；未决定的学习不能被场景抢先确认。主动道具执行前先判资格，执行时再检查目标和实际效果，不把只读预览当消耗凭证。
