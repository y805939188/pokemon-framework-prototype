# 回程的来源、抵达与存档

战败或野外全灭的 App 所有者与当前代次是回程的唯一授权。来源地图、玩家、地图数据、场景及已接纳的目的地不能用地图 ID、可复制 DTO 或旧回执替代。野外全灭不扣战败金钱；已提交治疗、统计和清理阶段不重做。真实目标到达与场景后台显示分别确认。

`reserveTransfer` 成功不表示玩家已经抵达。等待真正的 `performTransfer`、玩家刷新、目标坐标和原生生命周期。源的过期队列不能把旧天气或治疗点写到目标。`requestRefresh` 正常返回也不表示自动事件页已跑完。异常保留合法的稳定检查点；只有原所有者能退休相应私有请求。

新进程从标题选定手动档或自动档后，等地图与原生重新装图操作就绪，再做检查点未完成的阶段。没有检查点、目标改变、仍在恢复和非法快照不能新造回程。稳定失败可保存/显式重试；活动转移或等待期间阻止保存。旧连接真实保留的自动存档请求可交给真实回程，等实际 `onTransferEnd` 后与真实新请求去重，最多执行一次；没有请求就不制造。拒绝不自动补存。只有读回真实槽和全局索引，才证明磁盘状态，而不只是调用过钩子。
