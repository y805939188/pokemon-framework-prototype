# 存档、队伍与接收维护说明

## 迁移与接收

使用稳定内容及个体身份，不用显示名、战斗槽或临时 PID 猜。迁移只补真正缺少的兼容字段，不能把非法值当缺失；盒子超出允许容量时整体拒绝，不裁剪或覆盖档。当前边界见[迁移用例](../framework-remediation/migration-vectors.zh.md)。

捕获及礼物按容量安装在队伍或盒子。成员、计数和相关接收标记按同一次操作安装。若变更碰到已占用队伍或界面的状态，先核所有者、目标和代次；迟到结果不写入后继状态。合法的 pending 接收只从可恢复边界继续，不因界面重建再次发放。

保存入口需分别检查手动槽、开启自动保存时的自动槽和新进程从标题选择指定槽。直接调用读取或只等待 saveGame 返回，不证明真实槽文件及全局索引均落盘。作者入口见[使用指南](../user-guide/README.md)。
