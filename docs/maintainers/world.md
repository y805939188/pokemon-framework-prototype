# 地图与场地维护说明

## 正常玩法闭环

用[作者上手指南](../user-guide/README.md)准备内容、地图和插件；通过领取、遇敌、训练家事件、捕获、成长、治疗和保存组成流程。战败是否继续由场次设置决定；需要回程时，无可用家配置不伪造目的地。源码、发行构件、实机和编辑器重建分别验证。

## 伙伴归属

地图伙伴由唯一的原生生产者和应用登记簿确认。准备、绑定和发布重核当前 App、地图、代次和对象；旧事件、替身或缺能力不能授权。清理只退休自身，不清后来激活的事件。参见[地图作者说明](../step5/5.5/authoring.zh.md)。

## 传送与战败回程

回程读取真实原生来源和实际传送收据；冷恢复的地图身份来自真实构造与排队记录，不得在开始后给旧对象补资格。Map 数据尚未加载不等于缺少宿主能力。已提交前缀、到达待决和临时演出分别处理，失败保留已发生事实，显式恢复只继续未办阶段。

来源地图通知只在当前回程所有者许可的前缀处理窗口执行。同图菜单重建不算再次进入；旧来源通知不得覆盖目标天气、治疗、访问记录，也不能一律丢弃忙时通知。真正目标进入和清除回程检查点一次安装。原生玩家落地后同步请求地图刷新，再完成终局安装、显示和原生尾部；同步 Game_Map.requestRefresh 不等于事件页已经执行。失败恢复不重复预留、目标进入、治疗和统计。

只有真实 requestAutosave 才能延期，连接已保留请求可交给真正的回程所有者，并去重目标发生的真实请求。真实原生尾部完成后最多执行一次。无请求就不造保存；遵守原保存门，拒绝不自动补存。调用顺序和次数不证明磁盘落盘或冷读。参阅[原生回程接口](../step5/5.5/F-native-ports.zh.md)和[稳定恢复](../step5/5.5/f-stable-recovery.zh.md)。

## 场地道具与延期自动保存

驱虫提交使用原选择的 own-data 及原应用认可的返回；四参快照与调用证据不符，不能用 getter、Proxy 或复制对象补证。新地图接收凭据时重核当前应用、代次和对象；只退役旧范围，后继不受影响。失败不重发反馈，不伪造保存请求。

## 作者旅行接口与保存

- PSFlow.worldFlyDestinations 按当前地区、访问、开关和目的地条件返回完整候选，Fly 选择使用完整候选；Dig/Teleport 需要当前非蛋且学会招式的成员 ID，只有这两族询问确认。Teleport 先最近治疗点，再角色家、全局家。retryWorldTravel 只续当前合法阶段，cancelWorldTravel 只退役自身及其原生操作。普通指令 201 继续原生流程且保留 Surf，显式 transfer 由 preserveSurfing 决定。
- configureWorldTravelPresentation 接收普通 own-data 回调值，不调用访问器或 Proxy；配置不赋予业务权限。无配置就没有 Fly 回调，Fly/Teleport 用简短文字回退。进行中与真保留原落点的 retry 复用原拥有者快照；抵达后按原生顺序显示、单次 BGM、刷新、可选回调、等待及清理。失败不重做已提交前缀。项目的完整媒体演出另行接入。
- Dig/逃脱绳的原生载具释放不同于会前移的普通下船；释放真实载具并恢复步行/BGM，不额外消耗遇敌步。框架 Surf 与原生载具状态分开；可选自行车接缝不是内建自行车系统。
- 可选 fieldPresentationPending 只读取自有数据值函数，返回布尔 true 才为等待。缺失/访问器不调用；非 true 不阻塞。此门只是并入现有等待条件，不替代 App.saveBlocked；等待本事件结束才显示的同一事件 UI 队列不可反过来阻塞本事件。
