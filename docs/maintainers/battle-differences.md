# 战斗规则的取舍

框架用固定的 Showdown Gen 8 处理战斗内部规则，MZ 玩法入口支持单打。这里列出影响作者的边界，不承诺与另一引擎逐条等价。

| 情况 | 规则 |
|---|---|
| 已预留的道具未产生效果 | 只退款一次，不复刻重复退款。注册前就判定无效时，不花回合也不预扣。 |
| 成员倒下后升级 | 默认保持 0 HP，不用最大 HP 的增加量自动复活。 |
| 战斗中的持物和金钱 | 由生产引擎提供带所有权的结算凭据。区分消费、暂时失去、转移、归还；不能因来源缺失而把所有物品改成空。 |
| 经验和 EV | 会话按参与成员与战败对象处理成长；不要据单打外推同回合双打行动顺序的一致性。 |
| 训练家战投球 | 符合抛球前提时球被抛出并消耗，由训练家挡下。不能将「训练家战不能逃跑」作为退球条件。 |
| 逃跑 | 在引擎回合内结算；Ghost、Run Away、Smoke Ball 的保证分支先于 trapping 判断。 |
| 终局 | `reason: win` 要结合 winner；不是玩家获胜就不能按胜利发奖励。 |
| 大型战斗机制 | Mega、极巨化及 RPG 道具之间的顺序受引擎事件顺序约束，不承诺原版顺序或完整作者界面。 |
| 公开信息与反馈 | 确认的伤害、状态、场地、持物和招式才产生反馈；缺失能力与尚未观测的事实不能猜测。 |
