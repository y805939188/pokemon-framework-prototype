# 图鉴维护说明

## 图鉴登记与查询

- 图鉴规则读取规范化物种、展示形态、性别和异色，不读取引擎对象或对战文本。登记按展示形态命名，性别 2 写登记槽时归 0；最近外观按原形态命名判定并可保留性别 2。只知道已验证的基础物种时可按来源记录基种，不能补造未知形态。战斗出现／击倒需要内部战斗；捕获直接写 owned 不依赖它，内部捕获才另登记并计数。普通礼物不登记形态也可写 seen＋owned，静默加入在同样设置下只写 owned；进化／分裂／交换不等于普通形态提交。
- 击倒和内部捕获的计数每次合法调用累加，越安全整数边界拒绝；seen/owned 布尔不是去重凭据。去重和同次安装由应用账本和有效的准备凭据负责。独立更新最近外观只投影 gender/form/shiny，同值幂等，不重登、不改计数。是否展示新条目要保存提交前是否已拥有。清除图鉴数据保留资格、解锁和浏览布局。
- 编号分三类：解锁全国后 summary/brief 使用全国；否则 summary 停在首个解锁区，brief 继续找实际物种。完整单条 view=-1 按兼容行为查最后地区表并用偏移键 -1；该编号和 Area 的场景地区独立，缺省、null、负哨兵的场景回退是 0。地区数据级计数可返回 unavailable，列表可回退全国：不能把回退列表的本地游标按全国长度写回空地区，空地区持久游标只许 0。
- 未见占位不可开。中文排序键缺失进入 other 并诊断，不从 ID 补拼音；英文可用显示名。搜索参数按序为排序、名字组、两种属性、身高上下界、体重上下界、颜色、形状。尺寸索引 0–36、未选 -1 和长度 37 不是同一概念，筛选用 dm/hg 原值。美制重量保留两套历史显示：Info 和 Search 使用不同换算，例如 100 hg 在 Info 显示 22.0 lb，在 Search 显示 39.4 lb；这种差异只影响显示，不改变筛选边界。空搜索保持原已接受参数、列表、结果态和游标，仍可更新排序；结果态游标不落档。退出结果态按原物种恢复普通列表游标，无命中则夹值。取消草稿不写规则状态。
- 可选形态先过结构门：基础形态或有原始 formName 的非基础形态，且图鉴展示形态须指向自身。仅在 showAll 关闭时按已见形态及性别筛选；showAll 不绕过结构门。原始 formName 而非翻译决定合格后的性别枚举是否提前结束；翻译不改变行数或资格。各形态优先使用自己的性别规则；正面资源相等也可能是两者都缺，不证明素材存在。只有多于一条可选形态才创建最近外观选择，选中写 shiny=false，首末循环；退出不回滚已提交选择。
- Area 只消费规范化遇敌表、地图可见性与有限 ASCII 掩码。指定遇敌版本大于 0 时同时枚举版本 0；同格合并，可见区以外不画，短掩码不补。无可画点是 unknown，非法输入是 invalid。
