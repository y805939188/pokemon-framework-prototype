# 战斗维护说明

## 正常回合与道具守卫

战斗内的行动顺序及决胜由 Showdown 管理；框架拥有 RPG 道具台账、成长、捕获接收和最终写回。战斗使用稳定成员 ID，而不是在场槽位。游戏状态只接收经过校验的终局结果；同一个 battleId 的等价结果只应用一次，不接受同 ID 的不同结果。本规则不提供联网请求去重或战中存档。

回合动作先检查资格，再预留有效道具。取消、执行前失效、或战斗结束先于执行时，释放未消费的预留，且最多一次。训练家战中，在通过通常的动作资格检查、且未被 noBall 或硬锁（本回合必须续招）禁止时，可以投球；执行后球会消耗并被挡。训练家战不能逃跑，逃跑拒绝和投球被挡是两种反馈。野外逃跑在回合中结算；幽灵、Run Away 和 Smoke Ball 的必逃只优先于普通束缚，不绕过 noRun、硬锁或其他动作资格。低层双打情形不是首版玩家入口。

协议 v1 的 statusCount 保存剩余睡眠回合；旧记录没有该字段时，进战重新抽取睡眠计数。毒用 0/1 表示普通毒与剧毒的入场状态，战后剧毒写为普通毒，睡眠保留剩余回合。能力等级等暂态不写回；成长核对经验与 EV 上限，当前 HP 增量以变化前的实际最大 HP 为基线。消息形状与写集见[协议说明](../contracts/battle-result.md)及其机器合同；与参考的差异见[行为差异表](battle-differences.md)。

## 请求资格PP与回滚

菜单和提交使用一致的资格检查。引擎没有提供 PP 不等于可用 PP 为零；桥接层若不能表示永久招式的 PP 形状，先拒绝，不留下部分写入。内部检查点只恢复框架及引擎暂态，不回滚调用方已产生的外部副作用。

## 会话互斥与异常

同一会话同一时点只推进一项占用操作。若回滚失败，保留原错误和回滚错误，关闭旧会话，不继续从中提交。终局主结果不合法时退役关联操作，重试必须由新场次产生新的合法结果。见[应用操作合同](../contracts/application-operations.md)。

## 持物来源与结算

正常战斗要求正式持物来源；仅在明确的旧兼容模式下接受全空来源。不能因来源缺失或失真而悄悄降级成无持物。详情以[默认持物政策](../contracts/battle-capabilities.md)和[持物反馈合同](../contracts/healing.md)为准。

## 战斗界面与永久招式

持久招式和临时复制槽分别处理，不将临时战斗招式与 PP 写回永久槽。全屏学招退出时每层恢复其原可见状态，不一律显示。对战结果只展示明确授权的反馈，不猜测未知状态和数值。参见[主动治疗合同](../contracts/healing.md)和[招式 PP 与道具](../contracts/member-development.md)。

## 场地与证据粒度

进入危害和由位置变化触发的延迟/恢复效果，分别取证，不能互相代替。天气与地形有各自的状态来源；Mimicry 的类型清空和恢复按各自时点核验。只读路径、实际效果、完整宿主是不同级别，边缘情形和有限覆盖不能合并。参阅[场地归属](../contracts/battle-mechanics.md)、[地形通知修正](../contracts/battle-mechanics.md)及[适用范围](../contracts/battle-mechanics.md)。

## 功能范围与测试证明

构建训练家队伍时，成员拥有者的语言取自训练家记录（trainer.record.language）；省略时默认语言编号为 2。这不是参照版本等价或真实宿主操作的证据。StartTrainerBattle 已声明 MZ 插件命令元数据；静态声明不证明在实际 MZ 编辑器的插件命令选择器中能看到、选中并保存该命令。

框架首版面向单打。默认战前过渡不代表作者已能自由配置每个场景、对手和事件的注册及优先级。引擎多槽、合成内容、无窗口测试、真实 NW 与 MZ 各自只证明相应环境覆盖到的行为。当前使用和验收边界见[作者接入说明](../user-guide/integration.md)。
