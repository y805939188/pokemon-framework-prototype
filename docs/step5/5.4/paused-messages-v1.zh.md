# D2 暂停消息 v1：训练家开场消费者

依据冻结5.4 D-2/WP67-A §9.1及§3.2，承接已发布产品c93e783；不依赖普通消息bfa、招式拒绝或六维窗实机驱动的待批推送。只读取净化规格，不读原版实现。

普通消息保留原30ms/Unicode码点、全显实际更新起1000ms的合同。暂停消息复用同一文本时钟和owner边界，采用独立`paused-message-v1`状态：逐字中无续行箭头，USE/BACK/触摸只揭示余文；全显后有箭头，独立后续输入播决定音并关闭；同一次Scene.update重复取样不推进。全显后的正常自动驻留为3000ms，从实际全显绘制起算，迟到帧不能吞等待。显式战末标记为真时暂停不自动关闭；此为暂停呈现端口合同，不把已有终局确认页改成自动关闭。

生产消费者是训练家挑战文字和作者开场分页：按既有实际宽度/高度拆页，每页逐字、全显、等待完成后才排下一页及派出。保留显式换行和空段，未读完时菜单和选择持续阻塞、持久状态不写。取消、换档和失效owner退休原step、撤箭头，旧回调不向新场景重绘。现有`PSFlow.fast`仍仅测试专用即时呈现合同，不代表回放/可中止场景的正式计时。

不改作者台词数据、Session/Gen8/RNG、结算、背包或SDK导出。旧普通消息实机包仍绑定c93，不能拿它签本新逐字开场。brief驻留/清除、显式中间暂停/音效同步块、确认/命令列表忙态、野生开场包装、完整消息系统及完整D2/E/5.4仍OPEN。原GC WARN、U51 UNKNOWN、待批推送和全部旧失败/DEFER保留。
