# PC 根菜单正常状态刷新

S-1：根菜单 withdraw/deposit 的 enabled 在 pc() 创建菜单时固定。存入/取出后 refresh() 虽读取最新管理快照，却不更新既存根菜单，因此满队存一只后取出仍灰；反向取至满队也仍显示可用。

修复仅给PC根菜单标记，在每次 snapshot 刷新后更新它已有的两项 enabled。取出仍按 party.length < limits.party，存入仍按非蛋且HP>0成员数量>1，不改变原资格规则。保留菜单栈、游标、闭包、输入边界和管理token；不重建根菜单，不改变任何数据事务或持物门。

编译真实PS_Management、受控窗口/输入、真实App管理接口四条回归：6存到5、5取到6、2存到1、1取到2。验证返回根菜单正确启用状态、原游标保留、禁用项不导航不写入，以及新增可用操作确实可进入。旧产品4/4预期失败；修后管理UI、规则、查询三套68项通过，plugin类型通过。
