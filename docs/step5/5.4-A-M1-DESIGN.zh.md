## 字段消费者图（不是完成声明）

- `BaseMoney`：本批 A 奖金实际消费。
- `SkillLevel` / `Flags`：仅生成 C 的只读策略输入投影；C 尚未消费，未实现 AI。
- 训练家 `items`：仅生成 C 的会话资源所有权投影；C 尚未预留/执行/退款，未消费玩家背包。
- BGM/Intro/开场与胜负台词：仅生成 D 的逻辑请求投影；D 尚未播放或呈现，未实现正式 UI/战前演出。
- `Shadow`：C2 不支持，内容校验直接拒绝。
- 成员 `item` 可编译并进入纯队伍结果，但现有玩家与对手 held 双门保持；正常 M1 夹具无持物，带物对手在既有门前失败并标明 B 未支持。没有实验 gate 伪装生产支持。
