# 普通单打有效 Encore 的自动招式入口

依据冻结 D2 / WP67-A §4.1，有效可用 Encore 在单打 Fight 后直接登记对应招式，不打开手选菜单；本批基于已限定接受 `e48583e`，不含在审 `313751f` 成长/HM 组合。

复用现有 `BattleDriver.query`：`automatic-encore` 只在适配层确认当前单打、仍需选择的真实请求、当前成员的引擎 Encore 条件及唯一可选请求招式相符时，返回 `allowed:true` 与一基 `moveSlot`。不触发规则事件、不重新计算 Encore 规则，不返回 Pokemon 对象、未来选择或其它私有字段；Dynamax／非单打不提供本提示。其它查询和现有序列化请求不改。

查询结果只增加可选槽号，不新增 Session 方法、协议 v1 消息或保存字段。允许但没有槽号的旧适配器仍走手选，不能猜测。Scene 检查槽号范围及公开请求可选性，再经原 act/controller 提交；合法性和效果仍由 Session／锁定 Showdown 决定。单打不加多席目标提示或确认层。已有挣扎暂停入口先于此分支，原取消／拒绝／所有权处理继续复用。

真实 Gen8 训练家战控制使用明确作者夹具：等级1 Snorlax 只有 Encore，比等级100玩家慢。玩家先手使用第二槽 Growl 后，对手实际施加 Encore；中英两案验证跳过菜单、槽2一次执行、PP单次扣减、查询重复与返回值修改不改变引擎、空闲不串行动及持久零写。另验自然失效后恢复手选并最终保存一次、旧查询端口无槽号时手选、动作微任务前换档取消。原 step3 的真实 Fly／Recharge／Choice Band 各补一个“不应当作 Encore”断言，保留原断言。

窗口／字形／输入／音频／时间受控，不是 NW 证据。开场与部分测试收尾用 fast；单打 Encore 正常直接提交和后续消息路径不意味着整场 normal、真实输入或听感已验收。未修改 Showdown 上游、格式或 AI 策略。

本批固定后仍须独立复核、精确 CI 与必要原生验证；非单打 Encore 目标选择、成长/HM/挣扎最终组合、完整 D2/E/5.4/P4、既有 UI LOW、GC WARN/U51 UNKNOWN 和历史失败均保留。不运行 NW、不打包 APP、不推送或合 main、不更新总进度网页。
