# 捕获换入时的持物竞争优先级

本批补齐 `5.4-held-capture-order.md` 留下的同源优先项竞争规则，不修改 Showdown 战中转移、无捕获写回、物品来源 journal、协议或存档 schema。不称为原版等价。

满队 A 空手、B 携带 X。B 将 X 用 Trick 转给空手野生，再由 A 用 Trick 取走。捕获时把 A 送盒，A 的当前物 C 与留队 B 的恢复物 I 指向同一个来源实例。旧代码按 journal 成员顺序先到先领，数量不变但持物归属受队伍顺序影响。

新确定规则：

1. 所有仍在队伍的玩家成员先领取存活恢复项 I。
2. 所有送盒的原玩家成员再领取尚未被领取的当前项 C。
3. 两类各自按稳定成员 ID 排序。随后保留原玩家 current 回退、捕获成员当前/恢复领取及存活余项守恒补齐。

因此同源竞争时，暂时持有者 A 送盒不应阻止留队原持有者 B 恢复 X。无竞争时送盒成员仍保留当前项；已退休的消费/永久损失实例不会因优先级重新出现；同名不同来源仍是独立实例。没有捕获时保持原逐目的地 I/C 写回，返回 changes 顺序也不变。

新增 32 项测试：16 个纯规则与16个真实 App → Session →固定 Gen8 案例。涵盖双/三玩家转移链、异名/同名物、队伍前后顺序、分别把 A/B/C 换入盒；断言精确归属、总量、pending 零写、单次安装、重放及中止。纯规则同时检查无捕获路径和输入不变。旧用例继续覆盖无冲突送盒、消费、Harvest、永久转移及来源拒绝。
