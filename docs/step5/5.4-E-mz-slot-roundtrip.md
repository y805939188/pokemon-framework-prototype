# 5.4 E：普通 MZ 压缩槽的跨 Node 续接抽样

正式依据：工作区 5.4 计划 r2 §6.3（普通保存／下一战持物）及 §7 的证据分层；不修改生产规则、存档 schema 或协议。

本地专用命令：

```sh
PF_MZ_SLOT_HOST_ROOT=/absolute/installed-project \
PF_MZ_SLOT_PRODUCT_ROOT=/absolute/accepted-product \
node --test experiments/step5/4/test-e-mz-slot.cjs
```

两个路径必须显式提供，字节与 `e-mz-slot-contracts.json` 一致。测试不自动构建或修改它们，不在缺少宿主时 skip、造替代压缩器或自动寻找真实存档。

实际运行已安装 RPGReactor 的 DataManager、StorageManager、JsonEx 原类段、pako 和已接受 PS_SaveState 插件。保留 `saveGame/loadGame` 成功返回 0、真实压缩、`file1.rmmzsave`／global 索引、框架 JSON 编码和迁移钩子。仅注入最小非渲染 Game_* 对象和自有临时目录；文件访问限制在该目录。消费者仅获 case ID、目录和冻结运行时代码，不获预期中间状态。三案各启两个 Node：吃果后保存／新进程不复活果实、训练家临时打落后正常胜利保存／新进程恢复物品并再次真实打落、续战取消后原槽不变。另测无效框架状态拒绝、损坏压缩槽拒绝和宿主字节身份。

持物两项依既有 B 合同显式启用已审的应用 capabilities，仅为隔离验收；不声称默认正式入口已开放持物。战果由真实 Gen8 Session 经 App 正常 finish 一次安装，未走 legacy commit、诊断 tie、直接引擎篡改或伪造结果；战中保存受生产门拒绝。每次普通保存追踪槽和 global 写入完成，完整框架文档、账本及列举的 MZ 字段跨进程比较。

此层是实际压缩磁盘 I/O＋Node VM 宿主类，不是 NW、Boot、Title、Continue、Scene_Load、真实输入、完整 MZ 对象生命周期或耐崩溃保证，不关闭 §6.3 的全部义务。替身 Game_* 只承载作者合成字段，不验证地图／事件画面。未跑新的 APP、未访问玩家槽、未复制宿主源码入仓库。因需明确绑定本地安装的宿主代码，该套不注册为可移植 headless CI；缺少源身份时命令失败。完整 E 标题仍为零；本批只增加普通槽这一证据层。

野生对手按 WP47-B 不会移除玩家持物，故打落案必须使用真实训练家入口和一成员训练家；Splash 后由真实 Tackle 获胜，不用训练家逃跑或诊断终局。此夹具修正保留原野生期望失败，不改变引擎规则。

输出保留每阶段实际普通槽与 global 压缩字节的 Base64，供外部证据目录按原字节封存和独立解码；只有本测试合成文档，不含玩家资料。临时目录在命令结束后回收。
