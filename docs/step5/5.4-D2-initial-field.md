# 5.4 D2 显式初始场域

实施基于已独立通过的方案 c1231e35c7786ef95a7bea453ac3b190ab43c39b。方案的两项 P2 仅在合同层关闭；本实现仍需独立产品复核，NW 未运行。

`BattleStartRequest.initialField` 是每战可选只读记录：`weather`（none/sun/rain/sandstorm/hail/harshsun/heavyrain/strongwinds）、`terrain`（none/electric/grassy/misty/psychic）、`environment`（19项见方案 JSON）。省略及全 none 保持原有引擎行为。正式 MZ `StartBattle` 和 `StartTrainerBattle` 对应参数为 `defaultWeather`、`defaultTerrain`、`battleEnvironment`，默认 none。非法输入在建立操作、序号、音乐和场景前拒绝；异步入口保存分离的冻结值，后续调用方修改不改变本场。仅支持固定 Gen8 RPG 单打格式；不接世界天气 provider、地图自动推导、存档字段或全局“下一场”状态。

默认值在引擎 `onBattleStart` 建立、先于入场能力；无假造能力来源、无五回合期限。真实临时天气结束恢复默认并处理当轮默认残余；场地自然到期恢复，除雾／铁滚轮主动清除不恢复。当前存储的三原始天气拒普通四天气，即使天气被压制；保留合法原始互换和普通默认的合法覆盖。显示层只重排开场消息副本，默认通告在首发派出之后、入场反馈之前；中英词典含天气和场地建立文案，引擎事件原顺序和原对象不改。

环境消费者仅作用本次招式副本：自然之力调用真实映射招式，保护色走原生类型资格，秘密之力在独立 ModifyMove+1先生成附效，由强行删除或天恩倍增。实际身体命中后记录令牌，真实 hit-loop 结束按目标最多交原生求值一次；亲子爱真实击数、伤害和随机入口不改。none 和原生 terrain 委托旧路径。checkpoint 只串行化配置和原生当前状态，排除且 finally 恢复本批自有回调，restore 幂等重建；不重播默认／入场，不覆盖其他订阅。

可复验命令：构建当前引擎并在本树正常暂存 custom-formats 后，`node --test experiments/step5/4/test-initial-field-engine.cjs experiments/step5/4/test-initial-field-entry.cjs`。测试覆盖 IF01–12 的有限代码／编译 Scene 范围、各映射、覆盖及恢复、真实能力／多击、MZ双入口、跨异步封存、取消和单次安装；实际字体／像素／音频／实体输入／NW、完整 D2/E/5.4/P4未验收。外置证据记录原生 random 参数与原返回，不强制随机数、不把睡眠期限混入机会次数。S07在环境 grass 用真实 Jaboca Berry＋使用者HP1资格：原生实际一击、使用者倒下、目标存活，整招机会一次。不是把候选夹具文字当已执行。
