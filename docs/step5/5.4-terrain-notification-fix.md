# 默认场地恢复的 TerrainChange 单次通知修复

## 范围与合同

基线 `dcc804ae8a585ba92468b99181eca51246acfc89`，固定 Showdown `7244fe8e28fa8bc4d0809ae30d183c608b62bb2b`，Gen 8 RPG 单打。

本批只修复默认场地自然恢复时的重复通知。沿用 [显式初始场域合同](5.4-D2-initial-field-plan.md)：临时场地自然到期后恢复无来源、无 duration 的默认场地；直接 Defog / Steel Roller 不恢复。默认持物策略、Switch 流程、天气、环境招式和全局 Showdown 数据不变。

原生 `Field.clearTerrain` 在清空后发出一次 `TerrainChange`。默认恢复是第二次实际转换，需要另一次正常通知。原生 `Field.setTerrain` 成功建立场地后也只通知一次。修复保留“清空一次、恢复一次”，删除恢复分支第二个相同的 `eachEvent`；不屏蔽原生回调，不修改随机函数，不重新设计场地生命周期。

`Battle.eachEvent` 在分发前会按速度排序。同速成员即使没有相关能力或持物回调，也会在排序中推进 PRNG。因此本缺陷不仅是冗余无操作：在真实自然到期、普通同速无持物合成对局中，可以改变下一回合的平速先后手。本结论不代表所有种子、非同速队伍或实机存档都会出现可见变化，也不声称 Mimicry 或种子道具必然产生重复收益。

## 回归与控制

新增用例附加到已登记的 `experiments/step5/4/test-initial-field-engine.cjs`，无需改变中央测试清单：

1. 四种默认场地各经真实招式覆盖、五回合自然到期。观察真实分发，要求空场地和恢复各一次，恢复无来源、无期限，下一轮不重复。
2. 真正的 Galar Stunfisk / Mimicry 经默认 Grass → 临时 Electric → 原生 Ground/Steel → 恢复 Grass，保留真实 `onTerrainChange` 行为，并只收到两次转换通知。
3. 同速、Run Away、无持物、固定 seed `[1,2,3,4]`，分别验证到期后的 PRNG / 双方状态和下一回合动作顺序 / 完整消息。
4. 第3项的独立控制通过固定引擎自己的 `clearTerrain` 和 `setTerrain` 建立一次恢复，不改 PRNG、速度或行动队列。原生 setter 必须有来源，故测试控制使用自己的活动成员，完成后移除来源及期限元数据；产品仍使用无来源默认路径。控制只用于普通无持物样本，不把它视为所有来源敏感回调的等价实现。
5. 无默认的自然到期、Defog 和 Steel Roller 直接清除仅保留原生一次通知。
6. 到期前 checkpoint 恢复重建包装后仍只有两次转换通知，且与原会话的消息及 PRNG 相同。

新用例9项：旧实现1通过、8预期失败；修复后9通过。受影响三套为场域引擎89、入口15、训练家场域21，共125项，新增9已包含，不重复累计。入口套第一次因隔离树缺少既有 Reactor runtime 文件为8通过、7启动失败；补齐同身份依赖后15通过，保留初次失败记录。
