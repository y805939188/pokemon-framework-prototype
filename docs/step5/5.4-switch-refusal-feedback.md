# 5.4 换人的分类拒绝反馈

继承已独立限定接受的换人命令层dba3ece，本批按WP67-A §6.2补普通单打两种可公开确定的拒绝提示。实际chooseSwitch／chooseForcedSwitch返回choice-rejected后，读取自己一侧的公开成员状态和引擎当前待选择请求：所选成员已在场优先提示“已经在对战中了”，当前非强制请求明确trapped时提示实际换出者“现在无法被替换”；中英均本地化，沿原暂停消息／返回列表／稳定ID选中恢复。

显示分类不预先拒绝动作，不修改Session／Showdown资格、返回原因、RNG或持久状态，不解析引擎英文报错。没有公开确定信息时保留原通用提示；其它reason保留原提示族。读取最新公开待选择请求用于承接引擎实际拒绝后公开的trapped，不把maybeTrapped当作已确定，也不泄漏对方隐藏能力。Ghost等例外仍交固定Gen8引擎，成功不显示拒绝。

永久回归在真实App／Session及编译Scene中覆盖中英已在场／实际Shadow Tag束缚、Ghost正常换出、其它reason兼容；Shadow Tag载体为明确作者合成训练家能力配置，成员行为由固定Gen8引擎计算，不宣称默认Pidgey具有该特性。原九项确认／分层取消／强制替补等保留；测试受控宿主，不代表NW。

本批不补canSwitch作者规则入口或其显示门、不把束缚等同于该策略；同回合多席已选冲突、其它未确定拒绝分类、共享Summary／完整队伍、替补提议／野生继续逃跑、完整§6／D2与实机继续OPEN。默认UI轻微外观时序问题按用户原则后置，不扩低概率加固。R13-A-COV-1仍低优先OPEN，捕获ME测试只维护当前源身份guard。
