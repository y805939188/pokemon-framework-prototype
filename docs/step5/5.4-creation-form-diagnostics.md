# 创建形态的非致命作者诊断

装配成功后返回 warnings，按固定 Dex 规则物种家族和作者内容 ID，列出自动创建可能选中、但缺少受支持映射的形态。content build 与 content inventory 输出警告；inventory JSON 的 creationWarnings 保留可定位记录。失败装配只返回错误，不从不完整内容推导警告。

最初批次仅诊断 Toxel/Scatterbug/Spewpa；后续产品支持见 [有限持久创建形态](5.4-stored-creation-forms.md)。这三族合法 latent 形态现可通过有限基础战斗映射工作，不再产生虚假缺项警告。Wormadam 等机械不同的缺失形态继续警告且拒绝自动创建，不重抽、不缩小范围、不做泛化基础形态回退。

显式 player/gift 形态跳过自动重检。显式 trainer 形态保留普通 RNG；已存在的普通创建记录仍先参与原 metadata 计算，只有缺失且会被合法显式形态覆盖的中间映射可绕过。未指定 trainer 形态不获此豁免。

诊断规则不改变编译文档身份、注册顺序或存档schema。测试包括所有创建候选域、规则家族不由作者ID猜测、source门前Dex零读取及真实CLI警告。诊断本身不代表完整形态功能、NW、原版对照或5.4验收完成。
