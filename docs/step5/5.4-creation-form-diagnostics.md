# 创建形态的非致命作者诊断

装配成功后返回 `warnings`，按装配出的规则物种家族和作者内容 ID 的精确形态表，列出自动创建可能选中而内容尚未登记的形态。`content build` 与 `content inventory` 输出警告；inventory JSON 的 `creationWarnings` 保留可定位记录。失败装配只返回原有错误，不从不完整内容推出警告。编译文档、内容身份、运行时 Content 和存档不新增字段。

例如仅登记 Toxel 基础记录时，明确提示自动创建可能选择未登记的 form 1；Scatterbug/Spewpa 同样列出缺失的 1–17。规则家族来自固定 Dex 装配的 `ruleSpecies`，不以作者 ID 猜测。可能值枚举涵盖支持的环境、时段、玩家 ID、性格与随机值，属于潜在风险提示，不宣称每种实际配置都会失败。

警告不成为全局拒绝门：显式 player/gift form 0 等已可用路径继续可用。创建时仍保留 PID/IV/形态抽样顺序和缺失形态拒绝，不重抽、不缩小随机范围、不静默回基础形态。NPC 显式形态仍在普通创建后覆盖，警告明确说明此区别。固定 Dex 没有可用映射时不能凭空补出物种。

测试枚举所有创建家族的实际候选域并对比诊断域；真实固定 Dex 测 Toxel/Scatterbug/Spewpa、缺形态后8次抽样拒绝、显式0成功；作者别名与完整合成映射；source门前Dex零读取；真实CLI警告、成功退出和编译内容逐字语义保持。

这是作者诊断改进，不是自动形态创建规则修复，不关闭其未决合同。它不代表 NW、原版对照或完整5.4验收。
