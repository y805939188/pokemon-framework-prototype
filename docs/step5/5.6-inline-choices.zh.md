# WP17-A/B：单个内嵌普通选项

## 首片语法冻结

基线73decb2b。现有 `PS_Management → ShowMessage` 的当前语言正文可携带一个小写 `\ch[变量,取消,选项…]`，例如 `是否继续？\ch[13,2,"是","否"]`。正文结束后直接进入普通选择，结果写既有MZ变量，原事件在选择结束后继续。独立ShowChoices/ShowNumber/ShowTextInput仍保留。

依据为净化WP17 §3.2、§4、§7：变量字段按数字形式检查且接受0；取消字段作为普通字段转整数，正N返回N−1、负数原值返回、0禁止BACK，非数字文本转0。输入不复刻参考异常引号的宽松边界，本片只支持下列明确语法。

| 项目 | 首片合同 |
| --- | --- |
| 标签 | 每条当前语言正文最多一个小写ch；双反斜杠转义的ch是字面；不从姓名、变量替换值或选项文字再解析ch |
| 字段 | 单行逗号分隔；字段外侧空白去除；普通双引号包裹的字段保留内部文字，可含逗号和右方括号。引号闭合后必须紧接逗号或标签结尾 |
| 变量 | 去引号后的非负十进制安全整数，必须为0或已存在MZ变量ID；0沿宿主原赋值规则不产生有效变量写入 |
| 取消 | 完整带可选正/负号十进制安全整数；普通非数字文本（如no/取消）转0。数字前缀混杂、小数/指数等不在接受语法内，定位报错 |
| 选项 | 至少一个字符串，允许空字符串；默认索引0，不带帮助；文字原样进入现有字面选择呈现，不执行标签或替换 |
| 不接受 | 多个ch、空选项列表、未闭合引号/方括号、引号转义或嵌套语法、字段内换行；拒绝在取得消息所有权之前发生，不吞成正常结果 |

大小写扩展、异常引号怪例、多ch编排、内嵌帮助、隐藏/合并、原生402/403映射、命名、其它富文本、资源与持久化均不在本片。它不宣称这些排除输入与参考等价。

## 既有消费者与验证

复用ShowMessage逐字/等待状态、局部普通选择请求，以及正式Reactor `Window_Message.onEndOfText/startInput` 和ChoiceList退出。只在接纳作者命令时编译一次；正文结束交给宿主启动选项，不添加每帧文本/内容扫描。选项结果回调必须仍属于同一消息、窗口和场景，结果只写一次；正文到选择、选择到下一消息均刷新已消费输入。

定向验收使用完整PS_Management与正式解释器/消息/选择/变量消费者，覆盖时序、取消三态、变量0、非数字取消、字面/转义、失效回调、双语与三尺寸，保持原A/B/C/D入口。DOM、设备和位图受控，非NW。本任务只做轻量定向和独立小构建；正式binding/全量regular等待协调者确认5.5资源窗口，不自行启动。
