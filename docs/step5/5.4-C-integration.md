# 5.4 C：训练家策略真实接线的验收入口

本批继承 C1/C2、B 和友好度存档修复，目标是完成 C 的组合验证。作者证据与独立审查分开；本文件不是完整 5.4、Windows 或原版 Ruby 等价签收。目标为锁定 Showdown 的 Gen8 单打，不增加主动换人、模型推理、进程通信、难度档或战中存档。

## 策略和宿主边界

训练家类型可引用 `{id, version?, parameters}`，单个训练家可整体覆盖。默认 `basic-gen8@1`；受信 composition 注册实现，作者配置不能加载任意代码。开战固定实现、版本、参数与目录身份，下一战才采用更新。不同训练家可接不同策略；规则输入是冻结的公开战况和合法动作，输出是受校验意图。自定义异步实现与未来模型适配共用端口，但本批只用简单延迟测试策略，未实现任何模型。

`basic-power-proxy-v1` 是招式威力/命中/属性等有限元数据评分，非完整伤害预测；`basic-self-care-v1` 使用既定受控治疗门。纯 132 项保留这些评分、分支与随机消费合同。强制替补只在引擎要求时发生。Full Restore 的 999 是偏好估值；真实执行传当前目标 maxHP 或状态/混乱治疗的 0，不将估值当治疗量。资源属于本场 NPC，不扣玩家背包。

NW.js 渲染器和 CommonJS 使用不同的 Object/Array/Promise 原型。策略数据按描述符复制，允许真实跨上下文 JSON 原型，仍拒类实例、子类、自定义原型、访问器、稀疏数组。原生 Promise 用原生品牌操作接收，并封装原始兑现值，避免再次读取其 `then`；普通 thenable 不被同化。同步策略保持同步，取消/期限/来源/版本与重放边界沿 C2 不变。这是受信同进程 JS 的接口边界，不是恶意代码沙箱。

## 可复现命令

在已按 PROJECT-GUIDE 准备固定 Reactor、素材、依赖与 Showdown 的独立工作树中运行：

```sh
PF_NO_SKIP=1 scripts/test-quick.sh
pnpm --dir src build
scripts/package-mac.sh --with-tests --name PFTrainerAiC --out /absolute/new-package-dir
python3 scripts/run-trainer-ai-test-mac.py /absolute/new-package-dir/PFTrainerAiC.app /absolute/new-evidence-dir
```

宿主 runner 要求包由当前干净固定 HEAD 构建，核对实际产物 hash，拒复用证据目录。两个进程各自使用新 profile，共用新建的测试存档目录；只清理本次进程组。第一进程 6 个具名场景必须全部通过，第二进程 1 个具名 Continue 场景必须通过，空报告、缺场景、崩溃、超时、产物变更均失败。它不安装依赖、不打包发布、不修改全局 NW、不触碰已有用户槽位。

实际 MZ 场景使用受控作者数据、HP/异常状态前置条件、程序化接口和合成 DOM 按键；不声称实体键鼠输入通过。覆盖四种 Full Restore、重复事件、实际结算凭证/幂等提交、跨上下文延迟策略及同源检查点重放、正式训练家事件/战斗场景；保存后退出，下一进程经 Title → Continue → Load → Map 读取完整 JsonEx 文档，验证不重复安装，并完成下一场真实 AI 战斗。不是跨进程战斗中恢复。
