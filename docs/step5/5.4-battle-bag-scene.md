# 5.4 战斗背包首批真实 Scene 消费者

基于三核心整合 `93f07bf249ed2612da56fd32cc11f5ef93c97809`，本批接入已审的 `BattleBagSelection`，范围为现有内部野生／训练家单打的默认背包选择与实际道具提交。作者测试、独立代码复核、精确 CI 和真实宿主验收分列；本文件不授予其中任何一层接受。

## 已实现的接线

- 从当前 Session 公开的战斗数量、内容 catalog 和稳定成员 ID 建立快照。内容 item ID 与战斗 ID 分开，使用 catalog 映射，保留作者道具名称；没有读写野外背包游标。
- 默认命令窗口显示口袋／数量、显式取消和「使用／取消」子层。左右切换非空口袋，战斗内分别保存口袋和行位置；空背包仍可退出。成员、招式和对方选择取消回到对应层；蛋可见但不可选。
- 打开时隐藏已有战斗图片、状态框和消息，返回时恢复各自原可见性。Scene／操作所有者失效、读档、新游戏、结束和终止时退休选择状态，不让迟到回调操纵后继 Scene。
- 对现有 Session 支持的成员药品、场上 X 道具和球，通过实际 `canUseItem`、`useItem`、`throwBall` 提交。资格查询成功不算登记成功；异步提交期间锁输入，只有实际返回的 `ok` 才决定接受／拒绝。实际登记拒绝仍由 Session 负责一次退款，UI 回到原目标层。合法训练家挡球属于已提交动作，正常消费球。
- 菜单始终使用中英生产字典；打开使用子菜单的同次更新不能顺带确认使用。现有音乐 M08 和 step5 integration 测试导航增加使用确认，原业务输入、种子、结算断言不变。

## 验证与未完成边界

`experiments/step5/4/test-battle-bag-scene.cjs` 使用编译后的生产插件、真实 App／Gen8 Session，覆盖中英选择栈、空列表、真实左右导航、独立游标、稳定身份映射、药品／X 道具／野生捕获／训练家挡球、拒绝退款、异步输入锁、蛋和取消。绘制、音频与输入端口受控；这不是 NW、实际字体、物理输入或听感证据。两个旧控制器导航测试只补有效成员快照，原断言保留；前后失败日志另存，不改成首轮全绿。

本批不签收 WP67-A §5 全部：淡入淡出、成员／目标画面提示和高亮、非内部战斗生产入口、招式目标／无目标等尚无 Session API 的实际效果仍 OPEN。未支持效果给出本地化拒绝且不消费，不伪造成功。新真实包／驱动与宿主验证仍 OPEN，旧包和捕获 ME 十五项不因源码摘要更新而重新绑定。
