# 5.6 WP17：显式消息行数与原生分页

在普通地图事件的 PS_Management → Message 正文写 `\l[2]第一行\n第二行\n第三行`。本条窗口显示两行，第三行前保持忙暂停；确认或返回后清页显示第三行，全文结束再确认或返回，事件继续并恢复地图移动。它复用原生分页，没有实现 WP17 的一行平滑滚动。

单个小写 `\l[N]` 在本条正文显示前解析一次、适用于整条消息，可放在正文中的任意位置。N 是正整数，原生 `fittingHeight(N)` 必须不超过当前画布高度；例如本工程行高36、内边距12时，512×384最多10行。上／中／下位置继续按本条命令参数和实际窗口高度计算。没有标签时沿用原窗口四行。

真实换行、`\n`、`<br>` 共用该容量；`\nB` 也能换行后紧接英文 B，`\n[1]` 等已有角色名优先识别。实际换页字符（U+000C）仍走原生换页。字符逐字速度、定时等待、样式跨页及消息结束后的单个 `ch` 选项沿既有入口工作。

`\\l[2]`、变量或名字中的 `\l[2]`、大写 `\L[2]` 都作为字面显示，不反复解析。空、零、负数、小数、缺闭括号、多个行数标签或超出屏幕的 N 在接纳消息前报告既有 WP07 事件参数错误；作者测试模式的诊断指出 `textZh.l` 或 `textEn.l`。请保留一个有效标签，或用 `\\` 写字面反斜杠。

窗口在开始时按需要重建内容位图。原生清页复用该位图；逐帧、逐键和等待时不扫描正文或重建。最后一页在关闭动画中保持原样；完全关闭后，或下一条普通消息开始前，恢复原高度与位图。普通 MZ「显示文字」与业务 `$gameMessage.add` 保留原行为。

普通入口：Map005 事件17“5.6 WP17 explicit message rows”，坐标(14,6)。依次显示底部两行、中部三行、恢复默认窗口的消息和玩家气泡；不依赖测试插件，不写变量或框架状态。事件1–16及其它地图字段保留。

`experiments/step5/6/test-message-rows.cjs` 用完整编译插件、安装的 Reactor 解释器/消息/窗口几何/位图创建方法验证正式消费者。渲染表面、声音与输入受控。默认两行/高屏三行、皮肤、平滑滚动和其它富文本留待后续。

## 普通正文的词边界折行

ShowMessage 在开始时使用宿主字体测量，宽度取原生内容区减去文字左边距。后续词的累计宽度加 2 严格超过可用宽度时，该词整体移到下一行。前面的空白仍留在原行，连续无空格的中英文即使太宽也不会拆字。想在长句中指定断点，可以写真实换行、`\n` 或 `<br>`。

生成的换行进入原生分页。显式 `\l[N]` 仍决定页容量，内嵌选项仍等正文结束后打开。变量、姓名及转义后的文字只按字面测量。含实际着色、样式、文字速度、等待或显式暂停等控制的正文，以及 RTL 正文，继续使用原有布局。普通 MZ「显示文字」和业务消息延用宿主行为。

`experiments/step5/6/test-message-wrap.cjs` 用受控字体宽度检查 WP17 绘制附表 §3.1 的边界和正式分页、选项消费者。折行只在每条消息开始时计算，实际绘字依旧由宿主测量。NW、真实字体像素、特殊空白和画面中途变尺寸未验。
