# 5.6 WP17-D：事件光标字符网格

地图事件选PS_Management → Text / 事件文字输入 → mode: Cursor grid / 光标字符网格。它与原keyboard/free共用已有变量、初值、最小/最大长度和事件等待参数。默认仍keyboard，未新增玩家持久选项。此入口只返回本次文本到MZ变量，业务更名另批。

## 字符和导航

字符区5行×13列，四组UPPER、lower、accents、other的数据精确按净化WP17 §6.2.1，保留空格、变音、♂♀、希腊字母和符号身份。下面六控制依次为四组、删除、OK。

| 输入 | 行为 |
| --- | --- |
| 方向键 | 字符区左右同一行回绕，只跳过五行全空格整列；第12列始终可达；上下不跳过当前行空格 |
| 顶行UP／底行DOWN | 列0–1→UPPER，2–3→lower，4–5→accents，6–7→other，8–10→删除，11–12→OK |
| 控制方向键 | 左右六项循环；UP回末行、DOWN回首行，代表列0、2、4、6、9、11 |
| Z／Enter（USE） | 输入当前字符或激活当前控制，只有OK确认返回 |
| Ctrl（SPECIAL） | 四组循环，保留选择位置 |
| Shift（ACTION） | 只定位OK，没有确认音、不立即返回 |
| X／Esc（BACK）或删除控制 | 删末字符；空时仍留在网格，无独立取消结果 |
| 点击字符／控制 | 对该格执行一次选择；整空列禁用，第12列可达空格可以输入 |

同一采样轮方向优先LEFT→RIGHT→UP→DOWN，实际移动则本轮只移格；未移动时只执行SPECIAL→ACTION→BACK→USE中首个操作。方向+USE只移格、ACTION+USE只定位、BACK+USE只删除。BACK沿宿主重复等待/间隔支持按住删除。

## 编辑与结果

沿原入口max=1～32、min=0～max。初值不截短，超长初值可直接确认。满长插入先删末字再插入一个并定位OK，不整体截短超长初值。字符计数Array.from；第一组插入后文本位置为1就自动切小写，数字/空格同样。

OK上USE先确认音再查min，不足提示并留在网格，无蜂鸣。min0可确认空串；MZ原生value(id)将已写空串读为数值0，与原keyboard/free说明一致。结果只写一次，解释器等待场景回地图再继续。

网格是普通DOM按钮/文本，非编辑框，粘贴/合成不追加字符。方向/动作复用hostInput与InputLatch，仅本场景采样，状态变化才刷新。开场按住键先释放；关闭网格的Z/Enter到keyup前不确认下一消息，也不成为紧接keyboard/free的文字/确认，新按Z在keyboard/free仍是文字。未start、已关闭、旧请求、切场景排队/替换或变量宿主替换时，回调不写结果。

沿原生手柄逻辑输入，按住确认结束网格后须先释放再确认下一事件；场景清空输入不会把仍按住的确认视为新按键。释放由下一次原生输入更新观察，不另行轮询设备。该交接已用合成Gamepad状态和原生地图动作消费者核验，实体手柄仍未验收。
