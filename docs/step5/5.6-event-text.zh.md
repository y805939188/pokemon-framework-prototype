# 5.6 WP17-D：地图事件文字输入子集

地图事件选择 **PS_Management → Text / 事件文字输入（WP17-D 子集）**。结果写入已有 MZ 变量，等待编辑场景返回后原事件继续。这个入口只编辑本次文字，没有玩家、宝可梦、NPC 或存储箱更名目标。

| 参数 | 用法 |
| --- | --- |
| mode | `keyboard` 键盘命名合同；`free` 自由文本合同；`cursor` 光标网格见[独立说明](5.6-cursor-text.zh.md) |
| resultVariableId | 结果变量 ID，必须已存在 |
| initialVariableId | 0 使用对应语言初值；正数读取已有变量的当前值，转成文字，作为本次快照 |
| titleZh / titleEn | 中／英文提示，按当前语言选择；普通文字，不解释消息标记 |
| initialZh / initialEn | 中／英文初值；不截短已有初值 |
| minLength / maxLength | 键盘最小 0～max；自由文本 min 必须为 0；max 支持 1～32 |

## 原两种出口与后续光标子片

| 模式 | 插入与确认 | Escape／触控取消 |
| --- | --- | --- |
| keyboard | 新增字符逐个接受至 max；Enter 且长度 ≥ min 写当前文本 | min=0 写空串；min>0 禁止取消，没有取消按钮 |
| free | 同样限制新增；Enter 写当前文本 | 写回进入时的原文，编辑作废 |
| cursor（后续独立子片） | 字符网格选择；满长替换末字；选择OK确认 | BACK删除，无独立取消结果；见[光标网格](5.6-cursor-text.zh.md) |

初值超长仍原样显示，可直接确认；上限只限制新增，不缩短初值。支持普通单行输入、左右移动插入点、退格删除、选区替换和粘贴；删除后腾出的容量可以继续输入。计数按 `Array.from` 字符数。浏览器处理选择、键盘重复和退格；输入适配在插入后保留未变的前／后缀并限制新增部分。合成期间不确认，合成结束应用容量；复杂 IME、组合字素与极端 Unicode 不在本次签署范围。

**空串通过 MZ 变量原生赋值写入；MZ 的 `value(id)` 会把空串读成数值 0。** 因而消息 `\v[id]` 会显示 0，原生变量分歧也按宿主读取值判断。读取变量初值时亦沿用这个行为。本入口没有额外取消标记，空文本确认与键盘取消不能只凭变量值区分；自由文本取消结果本来就可能等于确认结果。

## 宿主入口与生命周期

沿用项目管理界面的 DOM 单行输入适配方式与共享 `hostInput.consumeNative`，以及宿主 `Scene_MenuBase`、`SceneManager.push/prepareNextScene/pop` 和 `Sprite_Button`。原生 `Scene_Name` 有 actor 更名写入，`Window_NameEdit.setup` 会截短初值；原生字符网格的布局与 WP17 不同，所以本入口不调用它们。本批没有新增全局键位或文字输入持久选项，两个模式由事件作者明确选择。

字段获得焦点后，Enter 确认、Escape 按上表取消；Z、X、空格作为文字。方向键和退格保留浏览器编辑默认行为。输入事件停止冒泡，已消费的 Enter／Escape 保留至 keyup，避免流入返回后的消息。现有 `touchUI` 开启时使用原生确认／取消图标回调；点击文本框可用宿主可用的软键盘。原keyboard/free没有字符面板；没有软键盘的设备需要实体键盘，后续显式cursor提供独立网格。按钮打开前、结束后和旧请求回调不写结果。

发起解释器使用局部 `psEventText` 等待，返回期间仍等待场景切换完成，随后执行下一事件命令。已有消息忙时本命令停在原索引；另一个解释器的普通命令仍可以运行。正常出口先写变量，关闭 DOM 编辑器、清输入再返回地图。地图事件在原有菜单场景期间暂停；自由文本没有新增地图微更新循环。未证明参考命名场景更新／动画顺序等价。场景被宿主外部终止时移除本次 DOM 和监听，不写一个伪造确认结果；异常宿主恢复链未签。

## 可达双语示例

Map005 **事件 14：5.6 WP17-D event text，(16,10)**。从新游戏起点绕过已有事件到相邻格，用普通动作键交互：说明消息 → 键盘命名（初值“你好”／“Hello”，max12，min0）→ 结果消息 → 自由文本（初值读取变量12）→ 结果消息 → 玩家气泡 → 事件结束与移动。只写示例变量12。第二次编辑按 Escape 可以看到原文返回；第一次按 Escape 后会看到宿主空值显示0。旧事件1～13及地图其它字段保持。
