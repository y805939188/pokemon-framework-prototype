# 特殊创建形态：有限持久身份支持

本批基于 4a30a8f，不改变 Showdown 固定版本、不新增存档字段、不改自动创建的 RNG 次数或候选概率。

## 产品行为

- Toxel 的 form 0/1、Scatterbug/Spewpa 的 form 0–17 是本批明确支持的持久创建身份。固定 Gen8 Dex 只有对应基础战斗物种，故仅这些有限域可以使用基础战斗数据。成员保存原始 form，入战用对应基础战斗名；不能从单一战斗名倒推出 latent form。
- 精确作者记录优先。Content.forms 和 speciesKeys 保持一对一的既有作者记录，不写入虚假重复物种或覆盖作者数据；不增加 registrationOrder 条目，不扰动训练家默认性格索引。
- 创建→获得/赠送/交换→存档、捕获稳定 ID 模板、进化源/目标、教学/回忆门均使用同一有限身份解析。图鉴按合法基础展示形态归一化，成员持久 form 不被图鉴展示改写。已有 PokedexForm alias 只应用一次。
- 捕获仍必须有本次稳定 ID 原始模板、匹配物种和合法正向映射。公开观察外观不得借私有模板猜测身份。
- 训练家显式 Form 不移除普通创建随机调用。普通随机形态有记录时，仍先使用该记录创建，保留原有友好度等 metadata，再应用现有显式覆盖。只有普通随机形态无记录、且存在合法显式 Form 时，才能用最终明确形态完成此前本会被拒绝的创建。
- 未指定训练家 Form 时仍尊重真实随机结果。机械不同的形态（例如缺少记录的 Wormadam）不会静默变成基础形态，不重抽、不缩小候选域。

## 证据

test-creation-form-diagnostics.cjs 在常规 headless 登记内，覆盖固定 Dex 候选域、各 latent form、RNG 顺序、精确配置/缺失配置、显式训练家0及非0、保留已有训练家友好度、真实 grant 与各类 receiveGift、稳定模板捕获、存档内容验证、捕获计数/外观、同战斗物种不同持久 form、真实进化 scan/commit、回忆及交易应用、跨级图鉴 alias 不重复归一化。
另跑已有 acquisition、evolution-commit、battle-effects-writeback、trainer、content、learning、trade 邻接套件。独立 Ultra 复核发现的获得/进化接线遗漏和 alias/训练家 metadata 回归已整改并增加回归。

## 边界

这不是所有物种形态的自动补全。非上述三族仍需作者登记正确的独立战斗形态；现有自动形态诊断继续提示缺项。Toxel→Toxtricity、Spewpa→Vivillon 等最终机械/展示形态需要相应目标内容记录，本批不能凭基础记录制造未登记目标。测试是项目合成内容和固定公开引擎的非 NW 测试，不代表原版对照、NW、音频实体输入或完整5.4验收。

本候选验收：框架、core、app 三套 TypeScript 检查通过，四类引擎/工具包构建通过；12个定向与邻接测试文件合计213项通过。独立 Ultra 只读源测试84项通过，复审整改后无剩余实质阻断。未运行完整274套聚合、未运行NW、尚未以这些局部证据替代发布CI。
