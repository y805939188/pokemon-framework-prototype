# D2c 音乐宿主资格：测试驱动与冻结准备

本后继从修复并独立接收的 `f3d7a57` 派生，只改测试插件／合成夹具／准备脚本，不改产品音乐、App/Session/Showdown、SDK或五秒准备时序。旧a521草稿保留；`battle-music-native-v2` 固定产品PS_BattleFlow字节为 `bed217e97e319335e40d239a36b0bdf052d01c78f3481c4a38aface989a95034`。测试提交的Git HEAD与产品提交分开登记。

`PS_BattleFlowTest` 仅在显式 `d2-music` / `d2-music-continue` 模式启用。必须带 `--ps-sound` 保留真实AudioManager；Chromium mute只隔绝物理输出，不代替原生解码／source证据。无过滤、空分母、未知输入或旧输入hash不得通过。失败即停止后继场景，不采用旧通用scenario的恢复后继续逻辑。

原独立合同的六逻辑组17项保持：开战/选项M01–02，引子M03–06，根回程M07–09，取消/继任者M10–13，默认/ME/新档M14–16，另一个新进程正常Title/Continue的M17。前五组在同一个自有宿主进程，最后组单独新进程；不是六个进程，也不是已经通过17项。特别用真实 `AudioManager.playBgm({name:''})` 建立合法None前态，验证R7继承；不能仅给fake对象赋值。

媒体使用本机现有ffmpeg原生Vorbis编码器（该安装没有libvorbis），从明确频率、振幅1000、44100Hz PCM生成有效Ogg；编码器要求双声道，来源WAV为单声道后复制声道。完整离线解码采样数、逐帧nb_samples总和、容器granule时长、源采样数必须在一个实测编码帧内一致。冻结实际采样／时长区间，不把编码末帧填充谎报为源时长精确相等。原生AudioBuffer必须落在冻结区间并有真实AudioBufferSourceNode/参数/偏移证据；offline decode不是NW验证。8秒ME纯合成夹具在首次执行前固定以跨越真实Scene启动和结果交接，不改变生产期限。故意损坏的Ogg与确实不存在的路径仅用于负控，不能当有效媒体。

驱动不替换AudioBuffer／AudioContext。取消、超时、接管场景对真实已解码buffer做受控ready通知延迟；记录原生对象和完整decoded元数据后才触发迟到控制，不把延迟控制称为自然解码慢。M02只延迟真实App创建完毕的Session返回；M09在MZ普通数据属性状态端口注入一次明确未写入的错误，原文档不动且显式单次retry，禁止自动重试到绿。

接收／图鉴／进化使用真实App+Session+根继续操作及公开API程序化回答，不声明完整管理、图鉴或进化UI验收；M15默认交接子例也用真实Session程序化终局，以保持原生ME仍在播放的窗口。其他正常战斗仍走实际Scene与合成DOM按键。M16通过真正Scene_Save观察slot/global落盘promise、完整状态／receipt／BGM登记；M17只能读取同轮生产报告hash和expected文件hash、同一隔离slot，正常Title/Continue/Scene_Load进入。不会写用户已有档，不把旧结果或旧APP转授新版本；MZ原有跨进程BGM恢复不承诺保持seek，战内回程单独严格核实际play偏移。

准备命令：`node scripts/prepare-music-native-assets.cjs NEW_ASSET_DIR`；固定干净测试提交后用 `scripts/package-mac.sh --with-tests --name NAME --out NEW_PACKAGE_DIR` 构建独立包。仅复制合格manifest列出的合成媒体，保留原有包中有意背景夹具，不使用工程img临时PNG。
