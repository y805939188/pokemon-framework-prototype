# D2c：正式 Scene 的开战 BGM、事件引子与回程所有权

本批继承内部音频端口7166f7a的独立限定通过，接到生产PS_BattleFlow；不是完整WP15/16或D2。前置纯选曲47a已正常推送并经精确CI204（155套2840、Python7+23）通过。新候选仍需独立复审和本版本真实宿主，不把端口或VM测试叫实际发声。

`battleMusic`插件参数接受JSON `{map,global,presets,defaultBgm}`，`openBattle(request,{music:...})`可显式覆盖本场上下文。map/global字段沿已接受选曲器，不推导5.5环境。raw预置先解析name/volume/pitch，冻结后只读；空值可取消对应预置。`PSFlow.setNextBattleMusic({battle,victory,capture})`及同名事件命令管理三个独立下一战音频预置，正常根操作完成只清本场捕获的版本；过程中设置的下一战版本不能被旧清理抹掉。abort保留预置，新游戏/载入换代清空临时预置。胜利/capture槽在此只冻结保留，消费者仍后继；不冒称四类全局预置和背景清理已经全部完成。

`begin`经公开`app.trainerRecord(id,version)`取得实际训练家展示字段，冻结到host op，再创建Session；不用App私有事实或Showdown内部状态。普通Scene.start调用一次已绑定op/generation的BGM入口，正常选择仍复用47a。后续修改输入对象或公开projection对象不改变已冻结曲目，非法设置在op发布前拒绝。无资源/后端失败留音频诊断，不改主战果或冒充正常播放。

引子是独立事件阶段：先`PlayTrainerIntro(trainerId,version)`，之后可放作者对话/等待，再`StartTrainerBattle`。程序入口为`PSFlow.playTrainerIntro(id,version)`返回token，`PSFlow.isTrainerIntroReady(token)`可查询。nil/空引子不请求/改记忆/建立等待；其它情况先保留世界曲及位置，再准备引子。事件等待到准备成功、缺失或有限失败/超时，并至少跨过一个后续Graphics游戏帧。同帧/加载中直接openBattle受控拒绝`trainer-intro-not-ready`，不把引子同帧覆成战斗曲。这里只保证阶段分离，不假造固定歌曲播放长度；作者可自行安排更长剧情。重复引子保留原世界备忘并替换旧请求；当前框架尚无通用cue计时器，PT58/59的外部Q计时交界仍是内部端口合同，不声称此处已接通通用WP15 cue。

新增内部`BattleMusicOperations`管理一条宿主音频时间线，不管理第二份战斗状态。Scene退出不是return owner结束：正常`close`后app/generation/op仍相符时，回程解码继续；成功后将音乐移交世界，旧Scene terminate不得停止它。接收/图鉴/进化根锁未结束不restore；根继续流程完成才恢复原位置。新战斗会退休旧pending return，保留尚未恢复的世界目标；旧回调不得覆盖新战斗。abort立即退休媒体，即使App仍需保留根锁恢复或业务结果已提交，也不改已提交结果。换档、新游戏、generation变化、外部音乐接管均阻断旧发布；state replacement在清理期间持有开战保留门，防止销毁回调重入开战后被旧清理覆盖。

7166的已知默认覆盖+原世界无曲组合在本批补齐：WP15默认覆盖抑制宿主stop，将仍匹配的自有默认曲移交世界，正常结束/Scene退出不再销毁它；外部新通道不能被认领。该实现不等于通用默认覆盖stop/fade、BGS暂停恢复、全格式搜索或全音频事件已完成。音乐选项仍在交付时由MZ缩放，MZ ME在播则保留既有延后BGM启动门。

验收分层：实际TS独立编译、生产插件Vite编译、真实临时文件与受控MZ音频/renderer/clock、真实App/Showdown Session组合，分别记录。包含异步open时冻结、事件引子跨帧、正常/无原曲/默认覆盖回程、接收和进化继续、abort/load/newgame、未通知generation改变、同步取消与清理重入、preset版本和陈旧Scene隔离。载入含正常校验文档与needs-content两条编译PS_SaveState实际hook；都是隔离控制文档，未碰真实档，也不是落盘/NW证明。
