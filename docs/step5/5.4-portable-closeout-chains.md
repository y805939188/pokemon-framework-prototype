# 5.4 portable closeout chain regressions

Candidate based on `df58a1d201121e35dde00db97696322d1a28dee7`; no product source changes.

The regular headless suite now registers:
- `experiments/step5/4/closeout-chains/test-held-management-chain.cjs`: compile the current PS_Management plugin in an owned temporary directory, drive actual menu handlers to give a Lum Berry, consume it in a real App/Session/Gen8 battle, assert no pre-terminal persistent writes and exactly one terminal install, reopen the menu, move Leftovers to an empty-handed second member and take it back. This is **not** an exchange between two holders.
- `experiments/step5/4/closeout-chains/test-status-capture-chain.cjs`: burn and sleep applied by real engine moves, capture, receive, move captured member to lead through management API, verify next-battle HP/status/count/PP, bounded real escape with explicit run outcome, single install, healing and a healthy third opening; abort leaves persistent state unchanged.

These are portable adaptations of previously independently reviewed local synthetic-host chains. Local admission roots and frozen runtime hashes are deliberately not embedded: ordinary regression runs test the current repository build. H3 frozen-admission tests remain separate and unchanged. Shared fixture construction uses the public sample and normal production capabilities, not a release override. The menu plugin is freshly built rather than loaded from an earlier package.
