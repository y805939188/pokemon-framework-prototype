# 战前地图菜单守卫

当前有效owner的普通Map包装pending（new/flash/transition/after/return-pending/return）期间，`Scene_Map.isMenuEnabled`额外返回false。真实Reactor `updateCallMenu`继续运行其原else分支，清除menuCalling；没有暂停地图图形或篡改Game_System菜单开关。正常返场、取消、owner替换后恢复原方法，原来被作者禁用的菜单保持禁用。真正离开源地图的失败保护不变。

有限控制用实际编译PS_BattleFlow与安装版Reactor的updateScene→updateCallMenu/isMenuEnabled/isMenuCalled/callMenu，以及实际解释器/CommonEvent/App/Gen8；渲染、输入、场景调度、地图传送及部分底层对象创建为明确替身。主解释器idle由并行公共事件357开战、flash键盘menu和transition触控取消不push菜单、不abort；缓存menuCalling被清除。自然完成/取消后新输入可打开真实callMenu路由的受控菜单Scene，busy主解释器对照和宿主禁用规则保留。撤掉编译菜单守卫必须产生语义失败。

这修复普通随机遇敌同样的idle前态，但本测试不冒称另外实跑随机遇敌或NW。新原生计划须显式增加idle开战菜单输入，旧503四案不追认覆盖。playtest debug键、3D parked解释器和其余P3不在本批，依独立r11合同后置；不得写已关闭。产品与驱动最终接受仍需独立复核、精确CI及独立实机，不合main。
