# Summary 排序后的单招 PP 道具身份修复

Claude V-1 在普通 Summary → Bag 路径中可复现，按 P2 处理。Summary 调整个体招式顺序，战斗引擎保留开场时的永久槽位；旧 Session 将个体下标直接注册为引擎下标，会恢复另一招，或在另一招 PP 满时退款但耗掉一回合。
