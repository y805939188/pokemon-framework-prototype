# 5.4 普通持物修复组合

本批整合已分别独立复审的刺刺针（6d742ce）、腐蚀气体（6e09abc）、战内捡拾（00714f4）、魔术师/顺手牵羊（499ee87）、野生拍落（d308837）及应用结算/磁盘重放测试（44eb136）。战斗执行以固定Showdown实际行为为准，接入层记录真实转移、消费与稳定成员身份，应用层按既有战后归属合同原子保存。没有用终局空物推断所有失物原因，也没有把旧资料与Showdown冲突的腐蚀/随机选择实现强加回引擎。

完整组合源为2cddae0752962b878b2e30ed75756736904b34f1。从最终源完整重建引擎和插件，E-status、E-defeat及H3的运行时身份合同枚举本次实际构建文件，保留所有历史绑定；业务场景、seed、oracle及身份校验代码不变。中间CI285因旧运行时pin未匹配新引擎而拒绝的历史不改写。应用生命周期新增套已纳入常规headless清单。

默认普通持物门仍关闭；本次不合并main，不授予默认开放、不启用5.5野生持物生成，也不声明双打产品、NW、全效果等价或真实玩家存档验证。各族受控实现和测试的限定结论仍适用。最终组合需普通速度独立复审及精确开发分支CI，不以中间分支通过代替。
