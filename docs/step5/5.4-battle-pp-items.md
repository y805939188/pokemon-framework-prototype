# 战斗背包主动 PP 恢复

依据 D2／WP67-A §5.2–5.3、WP28 §5.2 与 WP20 §5.4–5.5，在已限定接受 52c8c71 基线上接通已有战斗背包的成员／招式目标、Session 预留和回合内执行。与已接收 d1c8bf7 的野生倒下组合分树，不以它的结果代替本批验收；本树尚未合入野生继续／逃跑接点。

| 默认物品 | 目标 | 实际恢复 |
| --- | --- | --- |
| Ether、主动 Leppa Berry | 所选成员的一招 | +10，封顶 |
| Max Ether | 所选成员的一招 | 回满 |
| Elixir | 成员全部招式 | 各 +10，各自封顶 |
| Max Elixir | 成员全部招式 | 全部回满 |

默认兼容目录为三种单招物品登记 `battleUse: move`，两种全招物品登记 `member`；保留原场外效果，Leppa 保留树果口袋和 Berry 标记。显式作者目录仍须提供同族 battleId／battleUse，显示物品 ID 和执行 ID 仍按原目录映射，不按显示名猜效果。

目标必须存在、非蛋且存活；有效槽、有限正总 PP 和至少一个实际缺口通过才预留一次。单招取消回成员层；满 PP／濒死／无效槽拒绝仍留成员层，不登记、不扣量、不占回合。登记后取消与执行资格复检沿既有一次退款偏差；不改球、HP、状态、X 道具或原台账的语义。新增 `useItem` 可选 moveSlot 为零基永久槽下标；旧调用仍有效。PP 资格所需招式信息由 Session 的永久列表、公开引擎 PP 和原上限组合，不新增原始引擎对象或公开状态字段。

实际效果在自有 RpgAction 中按已登记顺序执行，不在 UI 直接写状态。永久 base PP 为权威；仅在场、非 Transform 且同槽招式 ID 相同才同步活动副本，Mimic 复制或 Transform 临时 PP 不被覆盖。使用既有行动后 PP 同步和最终一次结果安装，不提前修改原游戏档。普通道具消息沿既有双语字典，不将恢复 PP 数误报为 HP。

控制包含五种实际 Session 恢复／封顶、缺槽／满 PP／濒死拒绝、预留取消／登记失败一次退款、检查点和真实 Transform／Mimic 隔离；中英编译 Scene 走真实成员与招式菜单、取消／重复输入、实际恢复后招式 KO、最终 PP／库存只安装一次。窗口、输入、字体、绘图、时钟和部分 fast 受控，非 NW、实体输入或完整正常速度整场。

AI PP 道具评分、持有 Leppa／Ripen、PP Up／PP Max、复活和其它 direct 家族不在本批；原共用通用道具资格长尾未新增覆盖，不把本五种正常主动路径当完整物品系统。E 八观察、完整 D2／5.4／P-4、原 GC WARN／U51 UNKNOWN／LOW／历史失败均保持；本候选须独立复审、精确 CI及必要宿主验收，不自签，不合 main。
