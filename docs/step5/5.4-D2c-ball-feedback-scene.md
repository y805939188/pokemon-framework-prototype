# D2c Ball2：默认球绘制与 Scene 队列

继承已独立接受的 Ball1 `2558b44`（CI220）。本批将公开 `rpg/ball` 的纯计划接入实际编译 `Scene_PSBattle`。仅默认可替换呈现：私有红白占位 Bitmap/Sprite、投掷/挡开/吸入/聚合摇动/封合/脱出；不实现素材数据库或公共粒子动画，不改变捕获算法、库存、结果或 SDK。

`simple-ball-feedback-v1` 用 1/20 秒单位：投掷10、吸入4、每次可见摆动6、封合/脱出4、挡开6。普通可见摆动取 `min(公开checks,3)`，critical取1；公开 checks 原样保留，不声称参考版精确节拍或把四次捕获检查等同四次物理摆动。皮肤端口可替换；本版代码绘图不加载临时 PNG、不修改 ImageManager 缓存。

正常队列：投掷文字→实际球阶段→结果文字→既有野生捕获 ME/3500ms→经验/学招→数据框250ms淡出与球1000ms淡出并行→既有结束/接收。球及吸入画像在 ME/成长时保持，hide 起点是轮到该步骤的首次采样。轨道完成后下一 Scene.update 才推进；同次 update 多次读取不多采样，Battle Effects/fast 不跳必需阶段。挡球不吸入任何目标，脱出还原原目标；旧不完整事件/无可用公开画像保持文本回退。

球只操纵已存在的玩家对侧呈现画像与数据框，不新造目标或轮询引擎。实际 Scene 每 update 单增序号，端口绑 controller/op/app generation/当前 Scene。abort、换档/新游戏、terminate 退休球并释放自己的 Sprite/Bitmap；延迟旧回调不能画进继任者。正常 onEnd 也等本球收尾，失败/取消可退出。生命周期诊断 `ballFeedbackState()` 返回脱离的只读投影，不是公共战斗协议。

无头验证含严格纯模块/私有 MZ 绘图端口，以及真实 Gen8 Session 成功/挣脱/训练家挡球驱动实际编译 Scene：目标缩放、文本/ME/成长/一秒 hide/提交门顺序、取消及资源隔离。临时编译早放行变异必须转红。新增两套纳入 headless。首轮换档资源未立即释放的失败保留，补上既有 stateReplaced 生命周期中的球退休；原 ME 取消与停止确认断言不变。

兼容现有测试：控制 Bitmap 补实际使用的 fillRect；真实捕获测试等待投球结束再找 Gotcha，不删除 ME/经验断言。capture 原生合同测试仅更新当前源码摘要，历史 f021 的15项计划及包资格不改。胜利六链无头控制显式构建 **SYNTHETIC_CONTROL_ONLY_CURRENT_WORKTREE** 身份，保留历史 bbb5 JSON/冻结器原字节，实际原生仍必须拒绝不同产品；该合成控制不构成新包/实机接受。

本批作者无头/构建结果见工作区 `.verify/step5-4-D2c-ball-feedback-scene-20261102`；候选需独立复审。没有新 APP、NW、精确 CI、人工听感/键鼠或 Windows 通过。旧胜利6、捕获ME15、R8六、音乐17和所有 FAIL/WARN/UNKNOWN 分开保留。战前球/完整胜负反馈、capture-no-exp 及完整 D2/E/5.4、新 P-4、GC WARN/U51 UNKNOWN 均不因此关闭。不合 main，不更新总进度网页。
