# 5.4 战斗内共享摘要查看

本增量继承1943edb已在场／明确束缚反馈的独立代码／受控Scene限定接受，接正常队伍命令中的Summary。依据冻结D2、WP67-A §6.1与WP66-A §5，在原BattleScene内附加共享PS_Management摘要窗口，复用五页、成员导航和招式／缎带详情，不切换或销毁战斗Scene。关闭后按最后查看成员的稳定ID返回原主动／强制成员列表；强制替补根层仍不可退出。

应用的身份／原始性格／statNature／获得信息等静态元数据来自既有describeIndividual，动态字段来自当前自有Session和公开p1状态的副本：等级、经验、HP、异常、PP、成长EV和实际能力值。显示投影保留原始性格与Mint效果的区分，不拿旧持久HP／PP／等级冒作当前战斗状态。持物的C值使用既有required tracker的lineage绑定只读查询；这不是结束结算seal，不开放或降低结算资格。来源不存在／不可用时明确显示Content unavailable，不以初始物品或None代替。入口仅接受Session自有成员ID，结果深拷贝，不读对方隐藏来源。

查看期间原controller可视队列持有输入，Session／持久状态无新选择或写入，存档锁保持。窗口附加者拥有自己的窗口、内容位图和监听；正常返回／abort／换档／terminate释放，过期回调不操作后继Scene。没有打开beginManagement、物品／标记／存放事务；原管理战斗守卫保留。PS_Management缺失时显示可控不可用消息并返回列表。

公开投影门面加性提供readBattleSummary，与readGrowthDisplay同为只读入口；production与legacy门面绑定同一实现。精确导出名单测试仍拒绝生产、恢复与测试钩子，不放宽为任意read前缀。Session原型及冻结结果协议v1不增加方法或字段。

这是**共享摘要的只读接线增量**。WP66-A战斗内仍允许的招式／缎带排序尚未接入，应保留后继写入义务；不将禁写查看器声称为完整战斗摘要。完整共享队伍、蛋在Session过滤后的展示、排序／过渡、canSwitch显示门、替补提议／野生继续逃跑，以及共享摘要既有叫声／美术／细节缺口均保持原范围或OPEN。本批不引入新的编辑替代合同，不为微小默认动效差异扩修。

永久11项为真实App／Gen8 Session与编译BattleFlow＋Management组合，Window／输入／绘制／时钟受控。覆盖中英当前HP／PP和五页导航、实际升级、实际Air Balloon消耗、原始性格与Mint分离、来源未知显示、强制替补查看、三种owner退休和无管理写入。来源未知的共享渲染检查明确使用受控DTO；其余实际消费和行动由锁定引擎执行。没有新NW／原生字体像素／实体输入或性能验收。

空间策略：包依赖、libs和Reactor只读复用；Vite缓存、vendor生成声明及必要构建输出独占，结束核对共享源hash。仅必要5根APFS副本，不建APP或全树变异；新增目录及大文件用途记在作者证据目录。旧证据、WARN／UNKNOWN／DEFER保持，不合main或更新总进度网页。
