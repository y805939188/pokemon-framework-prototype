## 缺陷与处理

固定 Gen8 Showdown 发出 `cant` 事件时，普通 Scene 已逐个事件调用 `flow/describe.event`，但描述器没有 `cant` 分支；display 也正确地没有把它当作状态变化，因此这些事件没有可见文字。本批在描述器增加精确原因白名单，并通过原来的普通消息队列显示。

中英各覆盖睡眠、麻痹、冰冻、畏缩、行动后 recharge、无 PP、懒惰、着迷、定身法、真气拳、陷阱甲壳、挑衅、封印、重力、回复封锁和地狱突刺。睡眠只描述“仍在熟睡”，不谎称所有行动被阻止：固定引擎会先发 `cant|slp` 再执行打鼾或梦话。recharge 中文为“必须休息”，区别于 Dig 等两回合招式的蓄力／准备，不自行构造额外事件。

已知原因使用固定协议里的稳定成员 ID 和所属方，接受 Session 允许的完整安全 ID 字符集，仅从 names 的自有字符串属性取显示名。未知原因、缺失原因或非法身份给出不带角色推断的中性提示，不回显原始原因／附加参数、不拼接未验证本地化键。特别是 Damp、Dazzling、Queenly Majesty 等原因的首个身份可能是能力持有者，真正行动者在 `[of]` 中，因此未知能力不会被错误描述成“持有者无法行动”。这不是完整能力专用文案覆盖。
