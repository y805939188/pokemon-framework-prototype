# 5.4 每战经验／EV 开关

依据正式5.4 D2的战前规则注入及WP42 §4.1。`BattleStartRequest.expGain?: boolean`默认true；false在分配入口早退，不分配EV/经验、不升级/学习，也不清除该对手的参与者记录。它独立于捕获经验的全局规则，false同时约束正常KO与捕获成长；不改公式、引擎或持久存档schema。

App在调用外部端口前捕获并严格验证布尔值，经BattleSetup/composition交给本战Session。之后修改原请求、取消或checkpoint恢复不会重新读取请求值。旧自定义工厂可以省略setup.expGain，默认开启；实现该端口的工厂应遵守本战策略。

MZ的StartBattle和StartTrainerBattle均新增默认true的expGain布尔参数；缺省、布尔true/false和MZ字符串true/false被明确解析，非法值在递增事件序号/打开战斗前拒绝。该参数不是全局玩家选项，也不保存为永久成长设置。

关闭成长仍保留真实HP/状态/PP变化、命令/AI/对方替补、奖金、胜负与捕获结果、球消耗、胜利BGM和结束确认。主战果仍经既有确认后一次安装。Capture EXP结果由真实Session控制验证；完整捕获接收/命名/图鉴UI的该配置组合仍须后继宿主整体验收。

测试用正式App/Session/固定Gen8：两敌首KO保持等级5/经验269/EV0及招式表，参与者仍在；默认/true正控会升级到6、加EV并学Growl；请求突变、checkpoint、非法值/零create、捕获记录/扣球。生产编译Scene中英及两事件路径关闭成长后仍走胜利音乐/反馈和单次保存。Window/音频/时钟/输入受控，不是NW/真实字形/实体输入/听感。现有默认成长/HM/PP和音乐回归不放宽。

当前需独立复核及适用精确CI/必要实机，不签完整D2/E/5.4/P4。与待审Switch端口/PP/逃脱/复活/E抽样分支独立，未混入它们；所有旧FAIL/WARN/UNKNOWN保留。新增PS源绑定只用于当前headless源码检查，旧冻结APP/驱动/计划没有重绑或取得新实机证据。
