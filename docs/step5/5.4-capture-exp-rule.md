# 捕获经验全局规则与无经验捕获终局

依据 WP02 的 `GAIN_EXP_FOR_CAPTURE`（Gen8 默认 true）、WP42 §3.2／4.1／6 和 WP67-A §3.5，本批补齐作者内容配置的消费端。基线为已独立限定接受的 `70a127f`，不依赖另树在审的 fc477e5。

配置只接受布尔值；未配置保留原捕获成长。App 将全局规则捕获到本次 BattleSetup，再经正式组合交给 Session；直接或旧组合未给 carrier 时从内容配置读取，且在异步 driver 工作前固定。换档／取消及 checkpoint 不重新读取可变配置。它不新增玩家选项或每战 MZ 参数，也不改存档 schema／结果协议。

全局 false 时，成功捕获不调用该捕获成长分配，不增加玩家成员的经验／EV／等级或学习，不清其未处理参与者；球照常消费、捕获成员照常按既有接收流程加入、图鉴和最终结算保持。它不影响普通击倒成长。已有每战 expGain=false 仍同时关闭击倒和捕获成长，两门独立。

无捕获经验的野生捕获终局，经原呈现队列在捕获 ME／球表现之后补现有胜利 BGM；不改成 ME，不追加3500ms，不重新取得音乐 owner。沿用开战冻结曲目、原一次请求及取消／世界恢复守卫。经验开启路径保留原消费者，不以本批签完整音乐全部时点。

实际控制覆盖配置与严格类型、真实 App／Session／Gen8 捕获和一次接收、默认／true、普通 KO、每战关闭、工厂回调期间配置变化、checkpoint 和直接旧调用。编译 Scene 中英不提前保存、最终接收与扣球一次；受控 MZ 音频通道另查真实开始顺序／防重与世界曲恢复。解码、窗口、输入和时间受控，不等于新 NW／听感或整场 normal 验收。

不改经验／EV／捕获公式、概率、库存／接收策略、持物账本、Showdown 源码或 AI。fc477e5、来源旧失败／封印、GC WARN／U51 UNKNOWN／LOW／DEFER 保留。完整成长／捕获 UI／D2／E／5.4／P4、精确 CI 和适用宿主仍分门验收；不生成 APP、不合 main、不读原版 Ruby 或真实玩家档。
