# 5.6 消息入口与文字标签：WP17-A 首批

从 `459b2677c2f2d3f5ee69ffac19511499a5972a21` 继续，作者在地图事件中使用 **PS_Management → Message / 消息（WP17-A 子集）**。填入中文、英文文本和上／中／下位置；语言沿用当前 `PSFlow.translator().lang`，中文取中文栏，其余现有英文模式取英文栏。空译保持空串，仍需确认结束。本批不新增语言选择或翻译存储。

消息显示期间，本事件解释器使用原生 `message` 等待。文字按[玩家文字速度](5.6-options-controls.md#文字速度)出现，缺省中速。显示中按确认或返回不会加速、跳字或结束。到暂停点时按确认或返回继续；全文结束后再按一次结束本条（自动结束及选项按各自规则处理）。定时等待不能由按键跳过，选择「即时」也不跳过暂停、等待或选项。消息清除后事件执行下一条命令，事件结束后原生地图移动门自然开放。

## 作者可用标签

| 输入 | 本批行为 |
| --- | --- |
| `\\` | 一个字面反斜杠，例如 `\\pn` 显示 `\pn` |
| `\pn`、`\pm` | 框架玩家名、千分位金钱；不读 MZ 队伍金币 |
| `\v[N]` | 当前 MZ 变量的普通数字／字符串值；值作为文字插入 |
| `\n[1]` 至 `\n[8]` | 已有 MZ 角色实例名／数据库默认名（存在时）；不懒建角色，不是框架队伍成员名 |
| `\n`、真实换行、`<br>` | 原生换行 |
| `\l[N]` | 本条显式行数；单个小写标签、正整数且窗口须容纳于当前屏幕。见[行数与原生分页](5.6-message-rows.zh.md) |
| `<b>…</b>`、`<i>…</i>` | 嵌套粗体／斜体计数；在本消息中跨原生分页保持，结束恢复原字体状态 |
| `\ts[N]` | 从标签起覆盖本条消息的速度，每字 N/80 秒；`\ts[]` 和 `\ts[0]` 即时。不更改玩家设置。打开／加载完成后开始累计；迟帧可补显到期文字，动画／暂停／等待时间不计为待补文字 |
| `\!`、`\1` | 中间暂停，原生暂停箭头，确认／返回后继续 |
| `\.`、`\|` | 等待 0.25／1 秒 |
| `\wt[N]` | 等待 N/20 秒，然后继续，全文仍需确认 |
| `\wtnp[N]`、`\^` | 定时等待后继续并在全文结束时自动结束／全文自动结束；显式中间暂停仍生效 |
| `\c[N]` | **MZ 色板扩展**：复用宿主色板；不等于 WP17 的按皮肤明暗配色 |

消息正文按 WP17 附表的顺序解码 `&lt;`、`&gt;`、`&apos;`、`&quot;`、`&amp;`、`&m;`、`&f;` 一次。替换值沿项目业务消息的字面文本原则，不把名字／变量里的反斜杠或标签当指令执行。嵌套变量控制的递归展开未在本批交付。未支持的作者标记保持可见文本，例如 `<u>`、`\se[...]`，不会静默宣称已执行。

## 可运行示例

用 MZ 打开本工作树的 `game.rmmzproject`，在已有开发游戏会话进入 Map005，操作事件 **11：5.6 WP17-A messages and tags，(10,10)**。示例也包含在该地图的正常事件数据中，不依赖测试插件、开关或业务状态注入。

1. 与事件交互，显示玩家名、金钱、变量 1、粗体和换行；变量未赋值时沿 MZ 显示 0。
2. 在文字出现时按确认／返回，观察节奏保持；到中间箭头时确认，继续斜体、速度变更和 0.25 秒等待。
3. 全文结束再确认，进入第二条消息，证明后续事件继续。它另含 `\wt[5]`。
4. 确认后由原生事件命令显示玩家气泡并等待结束，随后可继续移动。

英文模式消费同一事件的英文栏。示例不写变量、开关、框架状态或存档；气泡使用工程已有 MZ 默认资源。示例给人工操作复现路径，本批实际验证为受控设备／位图上的生产事件链，未启动 NW 或执行实体键盘观察。

## 复用能力与兼容边界

继续使用现有 `Window_Message` 的绘制缓冲、Unicode 代理对边界、窗口位置、开启／关闭、分页、暂停箭头、`Game_Message` 清除，以及解释器与玩家移动守卫。新增入口只在进程内 WeakMap 保存其消息／窗口状态；其他解释器可执行普通命令，新消息遇忙保持本条插件命令待执行，不覆盖前条。结束沿原生输入刷新并额外请求输入／触摸刷新。

普通 MZ「显示文字」与现有业务 `$gameMessage.add`、战败提示、战斗普通／暂停／brief 消息继续使用自己的既有行为；它们不会因本入口获得 WP17 全部能力。暂停与结束确认请求系统决定音；默认出现音与其他音频标签未实现。没有新增窗口框架或全局输入规则。

## WP17-B：普通与带帮助选项

地图事件使用 **PS_Management → Choices / 消息选项（WP17-B）**。这是独立选项入口；前一条消息正常结束后再执行。沿用当前中英文模式，各语言填写自己的选项数组、帮助数组。选项与帮助是字面文本（可含真实换行），不执行消息标签、变量或姓名替换。空译保持空串。

| 参数 | 作者合同 |
| --- | --- |
| `choicesZh` / `choicesEn` | MZ 字符串数组；显示当前语言的列表，单列、宽度按文字测量、长列表原生滚动／翻页 |
| `helpZh` / `helpEn` | 可选字符串数组。省略、空栏、`null` 或 `[]` 为普通选项；非空数组启用底部帮助窗，默认项及光标变化同步显示同索引帮助；缺项为空，多余项不消费 |
| `defaultIndex` | 0 起默认索引；非空列表要求在列表内；空列表要求 0 |
| `cancelValue` | 整数：正数 N 按 BACK 返回 N−1（即第 N 项编码）；负数原值返回；0 禁止取消。正数取消编码不夹到列表范围 |
| `resultVariableId` | 选择已有 MZ 变量；确认写当前 0 起索引，取消写上述编码。沿原生变量赋值请求地图刷新；数值本身不能总区分确认与取消 |

随后添加 MZ **条件分歧 → 变量**，比较该结果变量。例如两项返回 0/1；`cancelValue=-1` 可另设 `变量 == -1` 分支。插件不会改原生「显示选项」的 402/403 分支编码，也不把插件命令的结果伪装成原生选择分支。

每轮沿原生选项更新先移动方向光标并同步帮助，再处理出口。BACK 与 USE 同轮且允许取消时，返回取消编码；取消值 0 时 BACK 无效，同轮 USE 仍确认更新后的当前项。单独 DOWN+USE 可在该轮先移动、再返回。方向沿／重复、上下边缘回绕和翻页复用宿主查询；确认与取消使用按下沿。正常出口请求额外输入与触摸刷新。当前事件使用原生 `message` 等待，结束后继续后续命令；其他解释器仍可执行普通命令，忙时新消息／选项保留在各自命令处等待。

普通确认用 `["是","否"]`、默认 0、取消 2；英文对应 `["Yes","No"]`，结果 0 表示是。严肃确认用 `["否","是"]`、默认 0、取消 1；英文对应 `["No","Yes"]`，结果 1 表示是。两者均取消到「否」，使用同一个入口和条件分歧即可。

### WP17-B 示例与边界

Map005 **事件 12：5.6 WP17-B choices and help，(12,10)** 可由正常动作键到达。先普通两项（默认乙，取消到乙），经原生变量条件分歧显示结果；再显示两项带帮助选项（默认甲，取消返回 −1），上下切换查看帮助，经 0／1／−1 分支显示消息，最后气泡、事件结束并恢复移动。两种语言用同一事件；示例明确写 **MZ 变量 10**，不写框架状态。已有事件 1–11 和地图其它字段保留。

普通数组 JSON `null` 在默认索引 0 时立即写结果 0，不建窗、不进入等待或请求循环尾部刷新。`[]` 则建空列表窗口并等待：方向不移动，USE 返回 0，BACK 按取消三态。带帮助缺命令的其它参考入口、`null` 配非默认索引、越界默认值及非字符串项不在等价范围；本入口对非法作者参数报错，不吞为正常结果。未选择有效结果变量也报错。无插件改写、默认宿主单列窗口为本轮支持条件；多列、运行中外部修改列表／索引、组合方向相互竞争、触摸与键盘同时竞争的参考合同尚未覆盖。触摸使用原生窗口能力；本轮设备受控验证不等于实体触屏观察。

复用 MZ `Window_ChoiceList`、`Window_Help`、`Game_Message`、变量和事件解释器。局部适配负取消编码、取消优先、空列表等待／确认、帮助同步与布局；原生相似行为不直接算 WP17 合同。默认系统窗口皮肤与光标仍按 MZ 绘制，不签 WP17 箭头图／皮肤明暗配色及精确像素。帮助窗两行，长帮助与长选项按原生裁切／换行能力呈现；作者应使用短标签与两行说明。没有新增全局输入规则或菜单体系。

单个普通 `\ch` 的正文到选择接线见 [单个内嵌普通选项](5.6-inline-choices.zh.md)，复用本节的字面列表、取消与输入消费者；独立ShowChoices入口仍保留。事件逐位数量输入另见 [WP17-C](5.6-message-number.zh.md)；命名／文字输入及相关业务后续。未改存档、读档、持续配置、新游戏／继续、恢复、计时或回程链。
