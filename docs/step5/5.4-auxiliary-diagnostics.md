# 附加事实诊断归因：有限修复

基于 0622070。原汇总把任何写回 skipped 显示成“部分战斗附加事实不可用”，包含合法 no-op、主结果 friendship 优先和等待后续进化扫描。本批只更换告警分类，不改事实生产、授权、战果、存档、进化扫描或持物门。

classifyBattleEffectDispositions 返回脱离输入的原因摘要，类别 complete/no-op/primary-wins/later-scan/degraded。只有明确白名单消除误报；resolved unavailable/invalid、写回 invalid、未知原因保持降级。即使 status=applied，display-form-unavailable/capture-form-unavailable 也仍降级，避免用局部成功掩盖外观缺失。later-scan 不是扫描已成功；后续 EvolutionOperation 仍独立诊断真正扫描失败。结果字段/协议不变，分类明细不写玩家存档，也不向玩家刷正常信息。
