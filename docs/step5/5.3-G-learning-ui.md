# 5.3 G1 学习 UI 有限候选

基线 main `b977ed7257ab66c5682a42ba51b5e60422f10304`，与 M1 双审候选0c同源码树。仅本批学习显示/输入接入；不签完整G/H、I/J或5.3。

`PS_Progression` 在 Inventory 后加载。依赖既有 GameApplication.beginLearning/resolveLearning 的公开应用入口，不改变学习规则、资源/统计写集、存档schema或冻结战斗v1。新增代码均在宿主呈现侧，核心不导入插件。`progression/learning-screen.ts`只保存当前页、嵌套选择历史和显示游标，不拥有Member或库存。

玩家路径：教学满槽先确认（初始Yes、BACK=No）→旧四招及新招行→BACK/新招询问放弃→No重选；HM拒绝留层。重学候选/确认教学/内层遗忘、退出确认分别返回，不把内层取消当退出。独立遗忘二次确认，允许HM，拒绝最后一招并可退出。空候选有消息和退出，无自由文本输入。

正常Bag/队伍“道具→使用”识别目录fieldUse=tm/hm/tr，不经过旧5.2未实现的机器资格路由；借用同一库存父token，源分别为bag/party，资源/PP/firstMoves/统计语义由原事务复检。界面不伪造兼容性、不默认消费；目标拒绝展示原因。机器路径按WP66A §7.2分开：Bag先开启消息/确认，再缓存逐成员ABLE/LEARNED/NOT ABLE显示；party Use先资格拒绝再开启/确认，不开第二选人。新增只读teachingCandidates查询复用同一纯计划，不产生安装/消费；选择仍由原事务复查。新增describeLearningMove通过已有内容/dex端口显示属性/分类/威力/命中/描述/总PP，缺资料明确占位。

本批没有改普通药品/糖果旧处理器；普通糖果/石/事件与进化共享演出的正式接入留G2，不能以G1关闭它。

事件命令（memberId必须为现存party稳定ID，moveId为内容canonical ID）：

| 命令 | 参数 | 行为 |
| --- | --- | --- |
| PS_Progression/TeachMove | memberId, moveId, source=tutor/generic | 教学并等待本屏幕 |
| RelearnMove | memberId | 重学候选与退出循环 |
| ForgetMove | memberId | 独立遗忘与最后一招保护 |
| ResumeLearning | 无 | 重开中断后的事务恢复页 |

作者脚本可用 `PluginManager.callCommand(this,'PS_Progression','TeachMove',{memberId:window.PSFlow.game().party[0].id,moveId:'slash',source:'tutor'})`，先检查队伍非空。Map005事件6提供学习Slash/回忆/遗忘三个实际命令示例；回忆是否有候选由当前等级/表决定。独立入口也可 `PSProgression.learn(intent,done)`，回调在返回父场景后交付；不能把该API当同步已完成。

所有输入通过5.1既有PSManagement.inputFrame与InputLatch；首就绪帧只采样、按住键必须释放、BACK优先于USE，未增加全局监听器。长名按测量裁切，PP单独留列；中英文自然文本与占位资源可用。本UI不新增原生命名/文字框，IME对这些离散页不适用；真实键鼠最终独立验收保持原用户决定，合成输入不能记硬件PASS。

技术失败：写前失败可重试同次或安全终止；已确认成功不回滚；真正部分安装由应用保持save barrier。恢复页提供回标题读完整存档，不能把不确定写入当取消成功。读档代次变化使旧界面结束，不释放新owner、不调用旧done。窗口初始化/绘制失败先安全终止自己事务，控制权回父；无法安全终止仍保留应用屏障，可显式ResumeLearning或读完整档。
