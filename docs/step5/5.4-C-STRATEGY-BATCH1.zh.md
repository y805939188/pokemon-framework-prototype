# C 策略边界第一批：同步候选，待独立复审

本批只固定训练家配置引用、受信 composition 注册、公开意图端口及同步替换。完整 C 尚未接收。此前暂停 WIP 单独保存为 `1a81740`（21 文件、未验收），本批在其上增量提交。完整原 30 项和新策略用例须由作者及父端复审分别验证；最新命令、结果、固定提交和封印见本轮外部 `AUTHOR-RESULT.zh.md`，不要据本文件预签测试结果。

`TrainerType.aiStrategy` 可提供 `{id, version?, parameters}`，`TrainerRecord.aiStrategy` 整条替换它。缺省是 `basic-gen8@1` 和空参数；记录的数字 `version` 仍是训练家记录版本，与策略字符串版本无关。引用在 JSON 编译、runtime 校验及战斗投影中沿现有内容路径传递，不新增持久 schema 或 PBS trainer 编辑器。引用整体限 UTF-8 JSON 8 KiB、根深度 0 至 8；只收普通自有数据字段，拒访问器、稀疏数组、symbol、隐藏字段、循环及非有限数值。每个受信实现还须严格验证自己的参数；basic 只接受空对象。

composition 的 `createTrainerAiStrategyRegistry()` 默认只注册 `basic-gen8@1`。开发者可在受信组装代码中注册实现和参数校验器，内容只能引用 ID/版本。无显式版本时解析该 assembly 的 active 版本；缺 ID/版本或错参数在创建正式战斗前拒绝。注册后同 ID/version 不得被替换，implementationIdentity 也不能复用。active 更新只影响后续战斗。开战捕获受信工厂，实例化后捕获实际 decide 方法，固定精确版本、实现身份、参数 hash 和目录身份；身份字符串不充当私有来源凭证。第二个槽位策略仅存在测试 composition，不新增生产难度。

策略只接收深度冻结的 detached `TrainerAiSnapshot`、参数和独立 AI random。先用与 basic 相同的目录/快照校验器验证 collector 输入，再执行策略；collector 错误不转为策略 fallback。策略不收 driver、raw request、source ticket、App/Store 或玩家未公开选择/pending。输出按描述符复制，严格验证字段、binding、诊断、候选及有限无重复 retry 顺序；首次 submit 回调前已有规范化 cache。实际提交仍以私有 ticket 对当前真实请求、候选、来源与资源复检。策略返回值及 retained aliases 不持有执行权。random 仅在同步 decide 期间开放。

本批端口只执行同步 `DecisionPlan`，返回 Promise 明确报 `trainer-ai-async-not-supported-batch1`，不等待它。原 runTrainerAi/driver 的 await 不代表安全异步策略。X1 是本批主要门；X2–X8 只有相关同步子项，整组仍未完成。第二批必须实现 1000ms 等待预算、单调 epoch/取消、attempt 局部 RNG、实际决定 journal 和 restore 只读 preflight；第三批再做完整 C 与真实宿主整合。本批不启动 NW host。

后继必须保持方案独审 N1–N3：规范化决定和 RNG before/after 在第一个提交回调前固定，执行结果另记；错误 checkpoint 不得取消合法 pending，合法 restore 必须先只读 preflight 再退休旧 epoch，并覆盖提交结果未知窗口；策略错误与 collector/source/partial 屏障分流。当前 cache/checkpoint 会回滚决定，尚不能保证非确定性策略 checkpoint 后只推理一次；不得宣称模型、journal、异步生命周期或缺版恢复已完成。

原四项失败的修复范围：collector 不再调用会自动写 pass 的 Showdown `isChoiceDone()`；真实濒死且 HP0 的 `fnt` 映射为无持久异常，活体非法 fnt 仍拒绝。C-L05 比较恢复前后引擎所有解析字段，固定测试时钟（Showdown 日志含真实墙钟 t 字段），避免把对象键插入顺序或测试跨秒误作业务重放差异，并用字段突变反控证明仍检出状态差异；不改 golden 或删字段。C-L13 的第二次变化在第二次实际提交资格检查前注入，原 checks=3 在首次重建采集前，属于该次重建合法采集的最新版本；另有单次变化正控。原红日志永久保留。gateway 对所有旧战斗都会维护来源观测，PP-less request 的缺省 PP/target 必须显式编码 null，以免旁路影响旧 Struggle/Recharge；旧 AI 本身未换策略。

SDK 必须同时导出生产 trainerAi 值端口、composition 注册类型及 testing/legacy diagnostics 的同一实例；portable core 只增加既定 trainerAi 命名空间，内部校验器和评分测试缝不进入公共 SDK。旧 S1/S6、协议/golden/input/mapping 不改。Showdown 固定 `7244fe8e28fa8bc4d0809ae30d183c608b62bb2b` / Gen8。可选 SQL 类型缺失诊断即使构建工具 exit0 也必须保留资格限制，不能称完整固定引擎构建绿。

公开 Illusion `replace` 事件不一定带 HP；collector 只沿既有公开条与历史保留，显示物种/类型按公开事件更新，不从真实 HP 补齐。SDK 的现有精确导出/投影断言同步登记新增公开字段，生产仍不导出诊断与评分测试缝。
