# Battle Effects 玩家设置与每战捕获

`PS_BattleFlow` 向现有 MZ Options 增加一项“Battle Effects／战斗特效”，默认 On／开，左右到端即止，确认切换。字段 `ConfigManager.psBattleEffects` 为布尔值，复用原 `makeData`、`applyData` 与原 Options 的保存所有者，不改变框架游戏状态 schema。合法新字段优先；只有新字段缺失时才兼容旧临时 `ConfigManager.battleEffects === false`，非法新字段回默认 On。保存数据只新增 `psBattleEffects`。

`StartBattle` 与 `StartTrainerBattle` 的 `battleEffects` 参数接受 `inherit`（默认）、`on`、`off`。直接作者调用 `PSFlow.openBattle({ ...request, battleEffects: false })` 使用布尔覆盖，省略则继承玩家偏好；其它值在开战前拒绝。此视觉配置不进入 App/Session 业务设置。

`openBattle` 在 Map 过渡之前捕获为 `operation.battleEffects`。后续修改玩家选项或原 request 不影响已打开战斗；下一次独立开战重新捕获。正式 Scene 将同一值传给图片、球与倒下媒体端口。关闭仅抑制既有可选效果轨道，消息、HP／经验条、派出／收回／倒下、投球／阻挡／捕获／收球以及成功旋律继续使用原等待和清理合同，不改变 RNG、消费、经验、战果或单次提交。

WP67-A§3.1/§9 与 WP65§5 为行为来源。持久性存在明确宿主差异：WP65 参考关闭选项不单独落盘；本框架沿用 MZ `Scene_Options.terminate` 调用 `ConfigManager.save` 的配置文件所有权。本批没有额外写档入口，不复制参考侧系统选项存档结构，也没有操作真实配置或玩家档案。

当前图片与球采用既有基础占位预设；没有新增完整招式／公共动画数据库或逐招映射。Effects-off 的现有基础阶段回归保留；设置与编译正式 Scene 控制覆盖默认、两命令、覆盖优先级、开场捕获、取消及单次数据提交。受控 Window／光栅／输入／音频／时间不等于 NW 或正常速度实机，完整 D2/E/5.4、P4、原 GC WARN/U51 UNKNOWN 保持开放。
