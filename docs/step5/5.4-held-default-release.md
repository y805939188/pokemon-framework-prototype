# 5.4 普通持物默认开放候选

本轮明确授权将原B-3“先合入再协调开门”的发布顺序改为：在独立5.4开发分支完成正常默认路径、普通速度独审及精确CI；不等待合main，也不合main。旧闭门批次的历史结论保留，本文是后续准入修订，不倒写历史。

唯一生产发布常量同时开放来源和入战，不新增玩家开关、存档字段、插件参数或环境开关。编译/组装、管理给予/取下、赠送/领取、交换、捕获接收及正常会话使用真实生产解析器，不注入开发覆盖。底层显式sourceAllowed=false仍拒绝；未知来源/不完整事实不能降级。

显式legacy-no-held兼容根不能因全局功能发布而失效。其实际玩家/敌方初始物品、捕获结果和模板仍必须为空，显式开发持物请求仍拒绝；正常生产根始终required，没有由错误或缺事实自动选择legacy的路径。以这种区分修复发布常量误阻断全空旧兼容业务的问题，而不是删去原授权测试。

候选验收包括正常七来源消费、取消/技术中止、零写故障重试、完整/部分安装故障、一次提交与重放、stats/dex、编译宿主及新Node进程磁盘Continue后携物入战。不扩大5.5野生持物默认生成；带物捕获只用正常Trick把玩家已有物转给野生目标后捕获，不伪造野生生成。Node宿主与合成档不代表NW物理输入或真实玩家存档。
