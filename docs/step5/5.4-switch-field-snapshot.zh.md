# 5.4 初始场域与 Switch 替补快照修复

范围：正式 App → 训练家 AI → Session 路径中，双方有后备、玩家使用默认 Switch，首只敌方倒下时的替补提议。任一非 none 初始天气、场地或环境会注册不可序列化的回调；旧 replacement-source 直接调用原生 toJSON，因 Format 对象抛错。Set 与 all-none 控制不受该故障影响。

替补来源现在捕获 Gateway 的场域感知快照操作，并统一用于准备、读取、目标校验、提交与恢复后的新票据。隔离预览及真实束缚探测克隆在运行原生事件前幂等重建场域回调。仍保留原生 switchIn/Illusion 预览、真实 TrapPokemon、来源快照一致性、一次性票据和检查点 lineage。回调排除仍由现有原子序列化实现负责，finally 还原原表，不排除外部回调。

新增 SSF01–10 在已登记的 test-switch-style-ports.cjs 内，共 22 项合成测试，连同既有 15 项。rain/grassy/cave 分别覆盖 Yes 与 No/list-cancel、反复只读查询、无效目标、PP/原生换人顺序、真实终局与一次应用提交、检查点恢复、真实暂存后的故障回滚。另含 all-none、Set、两类克隆回调、Illusion、序列化异常与捕获回调、真实 Ingrain、来源变化拒绝、异步中止和外部事件保留。

命令：`node --test experiments/step5/4/test-switch-style-ports.cjs`。须先以当前源构建 engine，且当前 custom-formats 构建与私有暂存完全一致。恢复断言比较完整 JSON 数据结构，不把原生恢复后的对象键顺序视为状态差异。

作者测试不是独立通过；固定提交与外部验证报告交独立复核。未改 TerrainChange 重复恢复事件、默认持物发布门、存档 schema、协议、AI 决策、场域规则或共享登记；不关闭其它场域、实体 UI/NW、对照、完整 5.4 或历史未决问题。
