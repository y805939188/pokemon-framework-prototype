# 普通连击的有限应用契约

按 5.4 §7、净化 WP46 §2／§3，核二连踢固定两击、冰锥的 2–5 击及连续攻击强制五击、目标首击倒下即停止，以及实际 PP 经生产 Session／App 单次提交。使用自有内存状态／投影端口，不改变生产代码。

六个冻结场景包含固定两击、强制五击、普通 2–5 击、首击击倒、连续攻击不把固定二击变五击、连击后中止。记录实际 HP 提交和 hitcount 对齐；整招只消费一次 PP，对手存活时行动一次，首击倒下时没有后继行动。玩家比对手严格更快，普通逃跑的首次结束前提由实际输入验证。终局前完整持久状态不变，结束单次安装／账本和重复 finish 保护，中止零安装。

每案同一 oracle 拒绝一份合成未扣 PP 的错读；不将其记作额外对局或引擎变异。自定义学招仅为合成作者内容，不保证官方学招；种子固定，不拦截随机数、不设置战内私有状态、不手工生成战果。

普通 2–5 击只检查本种子的实际击数范围及 HP／PP，不以一次运行证明击数概率分布。没有宣称完整 WP46 标题、多目标、替身、逐击特殊能力／持物反应、蓄力／连用、完整伤害公式、Scene／NW 或磁盘保存已通过。正式 E74 终态不在本批更改；历史失败和 WARN／UNKNOWN 保持。通过与否以固定候选的原始回执和限定独立复审为准。
