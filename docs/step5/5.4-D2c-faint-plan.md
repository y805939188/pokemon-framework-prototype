# D2c F1：倒下演出的纯选择与排期

前置伤害反馈`da606a4`已原ultra本地、独立Mac NW/MZ单轮98项及精确CI197限定接受。本独立后继只实现`src/plugins/battleflow/faint-schedule.ts`的纯内部函数，不进入SDK、不被生产Scene导入。固定候选仍需独立复审；构建或本批向量通过不表示实际倒下演出已完成。

依据clean规格WP67-A §9.3与WP15 §6.4，限普通非蛋、已登记物种／形态、资源稳定、正常读取与更新。调用方提供四个已观察候选，依次为专用形态、专用基础、普通形态、普通基础。每个候选明确为missing、resolved、pending或failed。只检查到首个命中或未决／失败的前缀：pending等待同一优先级，failed保留错误，不当作missing回退；下位候选不会被读取。只处理稳定值对象，不承诺捕获任意getter／代理异常。

resolved给出不透明assetId与文件秒数；本函数不解析路径、不查文件、不解码。专用音高100，d＝ceil(20t)+2；普通音高75，d＝ceil(20t/0.75)+2。无候选命中d＝12，不请求物种叫声。已命中零时长仍请求所选叫声且d＝2；有限负时长按公开入口归一到0并保留原数值、资源与音高。非数值、非有限值、缺失自有字段或下游毫秒无法安全表示的排期受控失败，不另换资源消错。这是适配器数值边界，不声称所有媒体异常都返回负值。

输出`faint-schedule-v1`为脱离输入的计划值：物种叫声起点0；数据框轨道起点0；到d才请求独立`Pkmn faint`音效、隐藏影子并开始主体下落。缺物种叫声仍保留独立音效。Battle Effects开或关均保留这些必需计划。d单位为1/20秒，是下落起始偏移，不是轨道总时长、墙钟音频长度或游戏帧数。计划只声明“全轨道停止后下一实际Scene.update观察完成”，本批不执行该观察，也不推导总阻塞时间。

`experiments/step5/4/faint-schedule-cases.json`中的12项期望来自净化规格的SOURCE_STATIC/DERIVED_VECTOR；测试实际编译TS，对每项分别运行两种effects设置，并覆盖优先级、未决／失败、零与缺失、数值／自有字段边界和输入输出隔离。它们是规格符合性测试，不是Ruby运行对照或媒体测量。套件接入现有headless/quick。完整类型／quick／build与运行产物／SDK逐hash比较记录在仓库外作者证据；不新起NW，把宿主项记为NOT_RUN。
