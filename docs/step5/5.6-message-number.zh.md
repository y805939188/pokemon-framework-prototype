# 5.6 WP17-C：事件逐位数量输入

地图事件使用 **PS_Management → Number / 逐位数量输入（WP17-C）**。选择一个已有 MZ 变量作为结果变量，再在「按顺序设置」中添加参数。默认无符号范围 0～99，初值读取结果变量的当前值；正常结束后结果写回该变量，原事件继续，可用 MZ「条件分歧 → 变量」消费。初值读取和结果写入只操作 MZ 变量，不涉及框架存档状态。

## 有序参数

每项通过 MZ 结构编辑器填写操作、值、范围最大值。后者只用于范围操作，其余操作忽略。按列表顺序应用，后设范围／位数覆盖前者。

| 操作 | 值与效果 |
| --- | --- |
| 范围 `range` | 「值」为最小，「范围最大值」为最大；最大小于最小时改成最小；显示位数由当前有效范围最大幅值决定，至少一位 |
| 位数 `digits` | 1～15；切换到位数模式，原始范围为 ±(10^N−1) |
| 允许负号 `negative` | 1 允许，0 禁止；允许时多一个 +/− 符号位。禁止时负的最小、最大各夹到 0；原始负范围仍保留，可再次允许负号 |
| 默认值 `default` | 设初值，同时清除此前显式取消值 |
| 初始值 `initial` | 设初值，保留此前显式取消值 |
| 变量初值 `initialVariable` | 「值」为已有 MZ 变量 ID；读该变量作为初值，保留取消值 |
| 取消值 `cancel` | 设整数取消返回值，不夹到范围；可与合法确认值相同 |

初值在打开前夹到最终有效范围；非数字变量值按 0，数值初值取整数部分。默认值／初始值栏是数值文本，非数值文本按 0。没有显式取消值时，BACK 返回夹限后的初值，编辑过的当前数字不会改变这个默认取消值。例：范围 [3,3]、取消 −71、初始值 99，确认仅能得 3，取消得 −71；把最后一步换为默认值 99，则取消得 3。

全负范围 [−9,−3] 禁止负号时有效范围 [0,0]，初值 −6 得 0；允许负号时初值仍为 −6。两位无符号初值 −12/−123 都得 00；有符号分别 −12/−99。取消值始终独立，不因无符号显示而夹到 0。

## 编辑、出口与宿主生命周期

左／右循环移动位光标，按住重复也循环；上／下循环修改当前位的 0～9，选中符号位时切换 +/−。符号与幅值分开，−00 可继续编辑成负数，确认零仍写数值 0。同轮先移动／编辑，随后 USE（Enter/Z）优先于 BACK（Escape/X）：合法 USE 播决定音、写值并结束；越界 USE 播蜂鸣、保留当前编辑并继续等待，同轮 BACK 不执行；独立 BACK 播取消音、按取消值结束。没有额外取消标记，调用者不能只凭结果值判断是否取消。

使用宿主 `Window_NumberInput` 的绘制、光标、窗口动画、逐位按钮和数字请求，局部适配这个新入口；使用 `Game_Message` 的忙状态、清除、解释器 `message` 等待及 MZ 变量赋值。地图仍沿现有宿主循环更新，本批不新增参考式地图微更新循环。忙时新插件命令停在原命令处等待，其他解释器的普通命令仍可运行。正常出口写变量后清除请求、关闭数字窗、刷新输入，事件继续并恢复地图移动。

启用现有 `ConfigManager.touchUI` 时沿用「减／加／确认」按钮与点击数字选位，并在本入口增加「取消」。取消按钮仅对本次请求可用；结束隐藏并移出按钮布局，原三按钮回到原生回调。打开动画期间和旧请求的触控回调不能结束新请求。原生数字命令 103、原生文本合并 103、WP17-A 消息和 WP17-B 选项保留各自行为。

## 正常事件示例

Map005 **事件 13：5.6 WP17-C digit number input，(14,10)**，从地图起点可绕过已有事件走到相邻格，用动作键交互。先显示中／英文说明，再打开带符号的 −25～25 输入（默认 12，取消 −99），结果写 **MZ 变量 11**。原生变量分歧区分取消示例与合法值，显示含结果变量的消息，随后玩家气泡、事件结束与移动。旧事件 1～12 和地图其它字段未改。

可试选十位、上调到 32 后确认：蜂鸣并停留，减为 22 后确认；或 BACK 返回 −99。示例使用取消哨兵只是作者选择，框架允许取消值等于合法值。示例不依赖测试插件或临时脚本，也不设置开关。

## 验证与保留范围

定向验证加载完整编译的 `PS_Management`，使用安装 Reactor 的数字／消息窗口、变量、解释器、地图通行与动作键分发方法体。包括参数次序、全负范围、有符号零、各位循环、编辑与出口竞争、蜂鸣后继续、变量分歧、窗口动画、真实键盘映射方法与按住重复、触控按钮复用及旧回调失效、中英示例和三尺寸布局。设备事件、位图及声音受控，未启动 NW，也未签实体键盘／触屏、像素或听感。

本入口支持 1～15 位，范围幅值不超过 999999999999999，显式取消值为 JS 安全整数；更长整数未覆盖，作者参数会报错。最小验证画布 512×384，使用默认 MZ 皮肤、字体、按钮；不签参考侧精确像素。多个方向同时成立、键盘与触控同帧竞争、运行中外部改参数及非正常宿主异常退出未覆盖。地图更新是现有 MZ 生命周期，未证明参考微更新顺序等价。

范围是独立事件数字输入；商店、背包件数、命名、全局输入和内嵌 `ch` 保留后续。未修改存档／读档、持久配置、schema、标题继续、计时、恢复、自动保存或回程。独立复核在固定候选上单独进行。
