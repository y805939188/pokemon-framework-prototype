# 5.4 战斗摘要：个体招式排序

依赖已接受并发布的统一候选5e321c0。WP67-A §6.1的Summary进入共享画面，承接WP66-A §6.1：已有招式详情中USE选择来源、移动后USE交换两项，BACK只取消预选；再次BACK退出详情，再次BACK返回原成员列表。交换完整招式记录，PP、上限及提升计数随招式移动，按稳定成员ID作用于所查看的自有成员。普通后备成员同样可操作。

持久游戏状态在战斗期间仍不可改写。Scene只持有异步命令及显示副本，Session companion在独占操作内交换工作个体，检查成员、槽位、预期招式顺序及待处理状态；不新增BattleSession原型方法、协议v1字段或管理事务。输入在命令完成前锁定，返回后重新建立输入边界；abort、换档、terminate使旧显示回调失效。Shadow仍属C2排除范围，仅对带该标记的受控来源防御性拒绝，不增加存档字段。

WP20 §5.5区分个体列表与独立战斗包装。排序改变摘要与最终个体顺序，不重排当前战斗的临时招式包装、PRNG或已发布行动请求。本场继续按原战斗命令槽位出招，PP按招式ID同步回工作个体；战后一次结果提交保存新个体顺序。排序后升级替换招式必须按被替换的永久招式ID查找引擎槽位，不能拿新个体下标误替换另一招；新增GrowthApplication.replaceMoveId只用于此内部同步，不改变学习UI所报告的个体下标或v1写集。未提供该身份的原适配调用保持槽位兼容路径。

本批接真实编译BattleFlow、Management、App及锁定Gen8 Session的受控组合。回归覆盖中英实际选择和重绘、PP/提升计数移动、继续出招与单次最终写回、后备稳定身份、取消与退休、非法/过期请求及checkpoint恢复、排序后真实升级满槽学招与PP写回。原只读测试保留“仅选择来源不写入”，补BACK取消预选；没有删除原断言。窗口、输入、绘制与时钟为受控宿主端口，没有NW、实体输入、字体像素或性能结论。
