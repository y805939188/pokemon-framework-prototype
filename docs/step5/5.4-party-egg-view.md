# 5.4 战斗队伍中的蛋与只读摘要

依据冻结D2、WP67-A §6.1与WP66-A §3.1、§5，接正常战斗队伍中蛋的显示和已有共享摘要入口。基线为已获独立代码／受控Scene限定接受的a1f2b01，继承只读实时摘要；不含兄弟分支状态外观1ec或学招取消3d3，不能用它们各自通过声称组合通过。

BattleSession／Showdown继续只接可参战的非蛋成员，不更改过滤、规则或结果。展示队伍从当前应用队伍取顺序，以稳定ID合并Session成员与未参战蛋；非蛋仍取Session记录，HP／等级等仍取实时引擎显示值。缺应用队伍或不能覆盖Session身份的最小宿主退回原Session列表，不伪造战斗成员。此处不新增战中调序或重新排列合同。

蛋行只显示本地化Egg／蛋，不显示物种、昵称、等级、HP、性别或闪光；命令只允许Summary／Cancel，不产生Switch In。蛋的摘要使用应用describeIndividual只读投影，不向battle readBattleSummary查询不存在的引擎成员。复用共享单页、左右夹页和INFO成员导航／非INFO跳蛋；摘要蛋头使用蛋标签并隐藏战斗数据，页名使用既有Memo。关闭按最终查看ID返回原选择位置；强制替补根层不能取消，仍须选择真实可参战成员。legacy物品目标仍用原Session资格路径，不扩大背包合同。

查看不获取beginManagement或写事务，不改持久游戏、Session工作队伍、引擎选择或随机数；已有owner取消／换档／terminate释放和后继保护继承。默认蛋页既有获得信息仍属原展示范围，完整Egg Watch孵化步数四档、蛋页完整备忘、美术／图标、完整队伍排序／交换、完整战斗Summary编辑以及canSwitch显示门仍OPEN，本增量不冒称完成这些功能。a1f的关闭后零尺寸纹理低影响问题继续LOW_DEFERRED_NOT_FIXED，不为此扩修。

永久测试复用真实App／锁定Gen8 Session与编译BattleFlow＋Management：原11＋新8共19项；新增中英蛋身份／单页／导航与无写入、夹蛋换人实时HP、真实濒死强制替补、三owner退休和legacy道具资格保持。Window、输入、时钟和绘制为受控端口；没有APP、NW、原生字体像素、实体输入或性能新验收。测试中不以直接构造request替代实际引擎强制替补。capture-ME-native只维护当前源hash，R13-A-COV-1测试缺口仍OPEN_LOW_PRIORITY。

当前仅作者本地实现／回归，固定候选须独立审查，CI／实机不预签。复用49只读约定依赖链接和5必要独立APFS输出根，不新增全量副本或APP；历史FAIL、GC WARN、U51 UNKNOWN、其它DEFER及完整D2／E／5.4／P4保持。
