# 5.4 事件战斗的禁逃跑／禁投球规则

按正式D2/WP67-A §3.1、§3.4及§5.3，StartBattle和StartTrainerBattle事件均提供noRun、noBall布尔参数，默认false。MZ字符串true/false与实际布尔值明确解析；缺省保持原行为。null、数字及其它字符串在递增事件序号/打开战斗前报错。参数经现有App→setup/composition→Session→Gen8规则传递，本批不修改这些已有领域合同。

noRun只禁逃跑，noBall只禁球，二者独立。禁止行为拒绝在登记和消耗前：不花球、不新增回合/敌方动作/招式PP或随机，也不改持久状态；拒绝信息按现有中英字典显示，玩家可返回改选正常动作。禁止投球不隐藏整个背包，也不取消其它物品能力。

默认false并非强制允许：训练家战仍禁止逃跑；正常投球仍消耗并被训练家挡下；野生捕获与队伍/仓库双满等已有规则仍有效。直接脚本/旧App的noRun/noBall语义不变。未增加全局设置、一次性通用规则表、天气/地形或非内部战斗入口。

实际注册事件/正式App/Gen8/编译Scene控制覆盖中英两入口、真实Run和背包Use拒绝后返回、保持引擎完整快照/请求/库存及单次最终保存、缺省/false正控、两旗独立和非法值零启动。Window/输入/音频/时间受控，部分fast夹具，不代表NW/正常速度整场。捕获正控仅验真实捕获/球账本，未签完整接收/命名/图鉴UI。
