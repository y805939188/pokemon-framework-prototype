# 5.4 作者的手动换人策略

按冻结D-2、WP67-A §3.1及§6.1，补正式StartBattle／StartTrainerBattle和脚本BattleStartRequest的canSwitch布尔项，省略默认true。应用在首个状态／内容／工厂回调前校验并捕获值，BattleSetup传给正式composition，由Session持有类型只读的本场配置；不是存档字段、冻结v1结果／foe字段或新的安全权限边界。新战可用另一配置，进行中的战斗不重读作者request对象。

false仅禁止玩家主动换人。健康非蛋的Switch In只有策略允许或当前为不可取消的强制选择时显示，Summary／Cancel与只读查看保持。Session.chooseSwitch也在取消既存登记／退款前拒绝禁止的主动选择，沿已有choice-rejected原因；不能只改菜单或凭chooseForcedSwitch方法名绕过。真实请求forceSwitch才允许强制替补，包括实际濒死及U-turn，后续合法性仍由锁定Gen8 Showdown判定，不改引擎规则、不把束缚当策略开关。原双打接口同样逐槽防止主动switch spec绕过；本轮只加策略拒绝控制，正式双打UI和完整新false策略双打强制路径不因此验收。

MZ布尔参数接受标准true／false及字符串，省略true，非法值在递增事件seq前报清晰错误。正式App／Session只接受布尔，不把字符串false按真处理；失败不创建Session、不改完整框架文档并释放应用开战所有者。原noRun／noBall／canLose与奖金等语义不变，不新增通用配置平台。

基线为已接受af7蛋摘要；不含f49／3d3学习、1ec状态外观，其它分支独立通过不能替代组合。原摘要、蛋稳定ID及owner生命周期继承；本功能仍使用可替换默认菜单，不增加美术和非必要动效。

永久回归在现有摘要Scene与训练家App测试中新增15项：中英false菜单／Summary、直接主动与伪强制调用拒绝且完整引擎快照／工作队伍／库存账本不动，已预留物品不退款，真实濒死与U-turn强制替补，显式true／既有默认兼容，两个真实注册MZ命令和非法值，App工厂回调前捕获及非法值释放，直接Session早期校验与已有双打API策略采样。实际App／锁定Gen8与编译Scene，Window／时钟／绘制／输入受控；假App工厂用于独立DTO捕获控制，不能全称自然宿主。没有APP／NW或实体像素／输入新证明。
