# 5.4：普通 Continue 的非渲染方法链验收准备

依据正式计划 r2 §6.3，承接已独立接受 `e71145f` 的实际压缩槽测试。新增四项正常流程控制：吃果保存后新进程 Continue 续战不复活果实；临时打落保存后 Continue 恢复物品并在下一场再次真实打落；损坏普通槽返回列表而不进入地图；没有存档时 Continue 不可用。

生产、旧输入和既有 worker 不改。producer 直接运行原 `mz-slot-worker.cjs`，consumer 只获案例ID、自有目录和冻结代码路径，从真实 global/普通槽读回，不注入预期中途状态。执行已安装 `DataManager.loadGlobalInfo`、`Window_TitleCommand.makeCommandList/isContinueEnabled`、`Scene_Title.commandContinue`、`Scene_Load.onSavefileOk/executeLoad/onLoadSuccess/onLoadFailure/terminate` 和 `Window_SavefileList` 的真实方法。`loadGame` 原成功返回0、PS_SaveState加载及状态替换钩子保持，地图请求后显式调用真实terminate方法，再开始真实App/Gen8续战并单次保存。

必须明确适配边界：Game_* 延续原e711最小对象；Scene_Base/Scene_MenuBase、窗口父类、声音和SceneManager只记录非渲染请求，不调用create/start、Pixi、地图更新或物理输入。global读取与loadGame观察器不改实际返回值；`onAfterLoad`是计数替身，未验证真实地图音频恢复。最小Game_System的版本查询与合成dataSystem均固定544，仅覆盖版本未变，不验地图版本迁移。读取的宿主类段只在本机运行时从固定hash文件提取，不复制宿主源码进仓库。新增scenes/windows身份与原四项宿主/插件身份一并核验。

显式提供 `PF_MZ_SLOT_HOST_ROOT` 和 `PF_MZ_SLOT_PRODUCT_ROOT`，以Node≥22.18运行 `node --test experiments/step5/4/test-e-continue.cjs`。此套依赖本机安装，不注册可移植headless CI；缺依赖不skip或回退。只使用自有合成槽，不查询宿主占用、不启动NW，不修改已安装文件或玩家档。

该控制链不能视为真实Boot、标题画面、SceneManager生命周期、正常Scene_Load绘制、完整Game_*恢复或§6.3全验收；真实Title/Continue/NW义务保持OPEN。新增的是方法链层证据，不新增E74或完整标题。当前候选作者结果、独立复审、全量、构建和CI分别登记；不借来源结果代签。不合main，不更新网页，原失败/WARN/UNKNOWN和追溯限制保持。
