# 战斗背包无目标玩偶逃脱

依据 D2／WP67-A §5.2–5.3 与 WP28 §5.5，基于已限定接受 d1c8bf7 接通 Poke Doll、Fluffy Tail、Poke Toy 三种默认玩偶的 `battleUse: direct`：选择 Use 后直接以当前行动成员为使用者，不经过成员、招式或对方目标选择。其它 direct 家族仍未开放，不以玩偶通过代表完整战斗物品系统。

默认兼容目录放战斗物品口袋，具有明确 battleId、消耗属性和场外不可使用身份；作者目录仍按原稳定内容ID→battleId映射。只在野生且规则允许逃跑、当前行动成员存活时登记；训练家战／noRun在预留前显示无效果并返回物品列表，库存、引擎和原游戏状态不变。不能将目标改为后备或其它成员。

登记沿原物品台账预留一次，命令取消只退款一次；实际效果在既有RpgAction物品阶段执行并复检野生／noRun／使用者。成功消费后发既有逃脱事件并结束战斗，不走普通Run的速度概率／次数或拘束分支，也不额外给予对方行动。使用既有run结果、友好变化和最终提交，不改变协议或存档schema；不声称战斗引擎的全部随机过程零消费。

中英真实编译Scene控制 Use／Cancel、无目标自动提交、重复输入防二次登记、确认前完整原档不变／安装0、确认后库存−1且安装1；普通Run被实际Arena Trap拒绝的控制中，玩偶仍能确定逃脱且命令逃跑次数不增加。旧请求的trapped属性为可选，不用它替代公开Gateway的准确拒绝原因。原无招／Encore／PP写回／野生倒下接点、背包模型、淡出和owner生命周期保持。
