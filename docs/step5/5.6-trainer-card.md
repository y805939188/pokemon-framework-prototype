# 5.6 只读训练家卡

普通暂停菜单增加以玩家姓名命名的入口，总是可见。确认打开训练家卡；返回键、手柄取消或原生触控返回按钮淡出后回到原暂停菜单，保留菜单选中项。确认、方向及 ACTION 不操作卡片。每次打开绘制一次，重开读取当前数据。

## 字段与来源

| 展示 | 现有来源与规则 |
| --- | --- |
| 姓名 | `PSFlow.game().player.name`，按普通文本绘制，不解析消息控制码 |
| 公开号 | 既有 `publicIdText(player.id)`，32 位身份低 16 位，五位补零 |
| 金钱 | 框架状态 `money`，千分位；不读取 MZ 的金币 |
| 图鉴拥有／见过 | 既有 `dexRegionCounts(dex, regionalDex, -1)` 全国基础物种计数，不随图鉴当前页、获得或区域解锁标记变化 |
| 当前地区徽章 | 既有 `currentRegion` 查询当前地图元数据；缺定位回地区 0。读取 `region × 8 + slot` 的真值位，八槽保留间隔，只绘制已得槽号 |
| 游玩时间 | **延期，显示 —**。现有 `stats.play_time` 为声明／初始化缓存，只有徽章获得时间消费者，没有生产计时更新。WP06 要求新游戏／载入设单调时间锚点、回标题清锚点、读取累加且不计离线；MZ 帧计数不等价。本批不引入计时生命周期，不把缓存 0 或旧值当成当前时长 |
| 开始日期 | **延期，显示 —**。没有已存在的合规字段；WP65 的开始时间懒初始化会写入持久状态，留待存档授权批次 |

## 规格与资源范围

消费 clean-room WP65 训练家卡附页 §1、§3、§5–6，WP65-D §5 的玩家姓名入口与返回，以及 WP24 身份、WP62 计数、WP63 当前地区、WP06 时间源合同。TC01 的字段子集与徽章稀疏位置、TC04 的 BACK 唯一动作、TC05 的公开号／金钱、TC06 的地区偏移已接入。TC03 懒写、TC05 时间、TC02／07／08 卡面与肖像资源合同延期。

本批使用已有 MZ 菜单背景、标准窗口、既有系统确认／取消音效和本地化字体；徽章以槽号占位。当前玩家身份没有训练家类型／装扮字段，本项目没有可消费的训练家卡背景、卡面、徽章图集或玩家正面图；本批不新增美术、资源身份或玩家字段。女性变体、装扮回退、正面图对齐和专用打开音效等待对应内容与资源，不签完整原版卡面等价。

卡片通过既有 Scene_MenuBase／SceneManager 生命周期退出与释放窗口。没有编辑指令、应用写操作或新持久状态。存档／读档、schema／迁移、标题继续、恢复、自动保存、回程、配置持久行为和名人堂不变。
