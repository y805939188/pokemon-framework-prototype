# 无招可选时自动使用挣扎

冻结 D2 / WP67-A §4.1 要求无招可选时不打开招式菜单，先显示暂停提示，再登记挣扎。本批在限定接受的 bfa71cd 上接这条正常单打入口，不改 Session 或锁定 Showdown 的战斗规则。

Scene 只匹配锁定 Showdown 明确发布的特殊请求：唯一 `id=struggle`、没有 PP 字段且未禁用。合法普通单招、带 PP 的已登记招式、Recharge 和混合可用／不可用请求仍走原菜单。不会由 UI 自行合计 PP 或猜测 Disable、Encore、束缚等领域状态。

Fight 后中英暂停消息复用已有逐字、首输入全显、后续确认和非终局三秒等待合同。显示步骤不提交动作；队列结束后核对原 Session 和完整请求快照，才由现有 controller action 调用一次 `chooseMove(1)`。消息期输入受原忙态门阻挡，abort／换档／terminate 后不执行旧意图；请求已变则回主菜单。实际合法性、伤害、反伤、PP 和战果仍由 Session／Showdown 决定，最终结果依原 Continue 单次安装。

真实 App／Session／Gen8／编译 Scene 控制覆盖中英暂停到真实挣扎、三秒自动继续、fast 入口、普通单招返回、三类 owner 退休及受控请求修订。窗口／声音／输入／时钟受控，不是 NW、听感或实体输入证据；中英案实际动作后切 fast 完成最终结算，不宣称整战正常速度。原 PP0 仍可聚焦、拒绝恢复游标及 Recharge 视图等七案正文保持，旧父插件的同两案应在“仍打开 moves”断言失败。

本批不包含在审 25a 成长组合或已单项接受 a3de HM；自动 Encore、非单打目标、完整成长／遗忘演出、独立 CI／必要原生和完整 D2/E/5.4/P4 分别验收。既有 LOW、GC WARN、U51 UNKNOWN 和历史失败保留；不打包 APP、不运行 NW、不推送或合 main、不更新总进度网页。
