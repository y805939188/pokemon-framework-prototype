## 输入、优先级与错误

程序入口拟增加可选只读值 `initialField?: { weather?, terrain?, environment? }`；正式 `StartBattle`、`StartTrainerBattle` 各增加三个字符串参数 `defaultWeather`、`defaultTerrain`、`battleEnvironment`，适配成同一值。各字段的省略、MZ 空白为未指定；解析后统一 none。显式 none 表示本战明确无默认，不能借用上一场。当前不增全局天气配置或可变“下一战”暂存字典，不增第二个操作所有者。

取值逐字段为“本次显式作者规则 → none”；不读天气 provider、存档、系统天气、创建个体的 creationEnvironment 或背景资源字符串。`battleBackground`、`battlePlatform`、`battleTime`、`prebattleLocation` 保持原来的独立呈现优先级，不能拿 indoor/cave/water 过渡分类冒充规则环境。环境可作为只读呈现上下文；缺少作者媒体映射沿既有 plain／代码回退并明确诊断，不另造世界推导或正式美术要求。

规范公开值与引擎映射全部列在 JSON。天气为 none/sun/rain/sandstorm/hail/harshsun/heavyrain/strongwinds；场地为 none/electric/grassy/misty/psychic；环境为 WP47-A 的19个明列值（含 none）。仅接受普通自有数据值与有限枚举，拒未知键、非字符串、null、混用世界天气标识、访问器或非普通对象；MZ 参数不接受自由 JSON。错误在创建会话／消耗序号／资源／新 owner 写入前报告，保持原档与已有有效操作不变。应用、Session、Gateway 各守自己的直接入口；不能只给 MZ 添加解析。明确 Shadowsky 属 C2 外且固定引擎不存在，snowscape 不是 Gen8 冰雹别名；请求这些值受控报 unsupported，不能悄悄改成无天气。

应用在原操作预留边界封存脱离调用者的规范值，只经 BattleSetup 传递；后改原请求、重复 begin 被拒、异步工厂迟到不得替换当前战斗配置。非法请求不取消已有第一场。没有单独持久字段、玩家档改写、普通操作证书或公开任意 engine mutation 权限。

## 初始化与默认生命周期

固定引擎的 `onBegin` 在 setPlayer 后建立 rpg；队伍选择之后 `onBattleStart` 才发生，此时尚无 active，随后 switchIn 和入场能力。Gateway 在双方 setPlayer 后、Session 的 team choices 前，将规范配置绑定到本场 `battle.rpg`。RPG format 在 `onBattleStart` 建立默认／当前场域，必须早于入场能力及首个可行动请求，不能在首回合或 Scene 绘制后补 setWeather。

默认不是一个有成员来源的天气／场地招式。原生 setWeather 普通雨没有 source 会在改字段后抛错，setTerrain 没 source 直接抛错；二者默认有限5回合，均不能直接充当默认初始化。实现拟在独立的 battle 内部 helper 中使用原生 EffectState、实际 Condition 和 format 的受支持 field 接点，建立规范天气／场地；不伪造活动成员、能力、岩石或道具来源。逻辑默认期限为 −1；Showdown 内部以无 duration 表示不计时，并显式在只读快照投影为 −1，不能把 −1 当普通 countdown 交给原生减法循环。

无字段或全部 none 必须走旧路径：原 format 回调／field 操作、开场消息、PRNG 和结果保持；不能为所有旧场景插入新通知或随机抽样。显式默认存在时，只在开场队列发布一次标准天气／场地通告，不伪造来源能力。领域在入场前已生效，Scene 仍按挑战／派出→天气场地通告→入场反馈显示；不能为排列消息延迟实际规则效果，也不重写原生 raw 记录。

入场 Drought／Drizzle／Surge 等继续由原生规则建立当前临时效果；不能让默认值永远盖住后来的合法覆盖。默认字段始终保留，而当前字段照原生消费。普通同种建立失败、不刷新、天气压制／接地／能力／PP／伤害／随机均仍由引擎决定。

临时效果到期不能丢失默认。本批必须实现并验证：普通天气临时覆盖自然结束后恢复默认无限天气；非默认原始天气来源离场后的正常解除恢复默认；场地自然结束恢复默认，直接除雾／铁滚轮移除不立即重启。不是旧临时效果栈，不恢复被覆盖的临时剩余数。

最小实现拟只在 RPG format 的 `field.clearWeather`／`clearTerrain` 接点包装原生方法：先保留清除入口与旧状态，再让原生完成清除；仅当对应默认存在且当前仍为空时恢复。场地只认原生到期将原 state.duration 递减至0的路径，直接移除不恢复。天气到期后恢复的本轮持续处理不能丢失，须按原生对应 Condition 的残余处理顺序执行且最多一次；正常能力清除不能冒充回合末再伤害。恢复后若原生回调已建立其它当前效果，不覆盖它。这里是待独审的最小接点方案，实际实现必须以真实回合末／能力离场回归证实；不能用只读字段赋值探针证明生命周期已完成。

配置和当前场域沿本场原生 checkpoint 序列化／恢复，同源校验保持。恢复不得重新跑默认开场或入场能力，不从调用者 options 改默认；新战、abort、新游戏／读档均以新操作配置或 none 开始，不把上一场场域带进持久状态或下一场。

## 环境必须有消费者

单存 environment 字段、只换背景不算规则环境已实现。Gen8 原生 Nature Power、Camouflage、Secret Power 只查当前 battle terrain，不查框架环境。拟使用既有自定义格式的按次招式扩展接点，在当前无对应 battle terrain 且 environment 非 none 时应用 WP47-A §3.3；存在原生 terrain 或环境 none 时完整委托原生实现。

只作用本次 move 副本，不改全局 Dex 记录：Nature Power 选择实际存在的对应招式并保留原生调用链；Camouflage 使用原生 setType／失败与类型可变资格；Secret Power 只给本次原生击后处理提供环境对应的30%附效，保留 Substitute、Sheer Force、免疫、PP及一次原生抽样。环境→招式／类型／附效的19行映射在 JSON 明列并以正式规格为来源，不增加新招式数据库或伤害公式。默认 none 的现有行为逐字保持；不据本合同承诺参考畏缩标记／媒体错拼等细节已与 Showdown 等价，这些只列差异，不偷修引擎。
