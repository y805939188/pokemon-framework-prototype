# 5.3 E3 学习动作应用接入（有限批）

基于E2b固定9fd8c1b后继；E2b现已PR12接收为main e9e2b915（CI101双层90/1468），本分支正常merge该主线，E3自身尚待双审/精确CI/接收。整体r3和06ac合同不变；本批只接通已双审的教学/机器/重学/遗忘纯计划，正式G界面和事件命令留M1后。

`GameApplication.beginLearning(intent,parent?)`接受party稳定成员ID和显式generic/tutor/machine、relearn或forget意图。机器必须绑定真实inventory父token，Bag或Party来源由父上下文核定，不能用调用方entry伪造包装统计。`pendingLearning`仅是无权威的副本；`resolveLearning(token,revision,decision)`给当前问题答案，资源/资格不由答案提供。UI和脚本不得给debug/compatibility/friendship权威参数；Shadow只取应用可信world端口，当前无Shadow实现。

operation在首次state/content/world回调前预留，阻止战斗、治疗、领取、其它管理/背包变更。management和inventory父子锁从准备贯穿选择/安装/失败恢复；父不能先关闭，snapshot可读。`PSFlow`只有程序化begin/resolve桥和绑定token的psLearning等待模式，保存仍用已有应用OR守卫；不是教学界面已完成。

使用真实内容精确形态表、实际机器目录/库存，先复制初始状态，再回放纯学习决策。成员moves/PP/ppUps/firstMoves/friendship、库存和包装统计一次安装；pure plan已含friend和资源，应用只安装统计delta一次。Bag TR追加firstMoves与机器统计；Party机器不加Bag包装数据，均仅满槽替换分支触发machine友好。真实目录fieldUse决定TM/HM/TR及耗品，不能根据道具名字。HM学习保护与独立遗忘允许HM/保护最后一招区分；空候选可退出，旧零招仍合法。重学三层取消不计成功统计。

选择后内容强identity、整个目标/库存状态与世界事实变化都会永久退休原意图，A→B→A不能复活。正常I/O暂不可用可重试。token/revision防迟到，完成后进程内最多32个结果回执用于同答案幂等，不新增持久workflow/事件账本。

准备、成员、资源、统计全ready才有next；真正写前再核所有权/状态/身份及save gate。写后以完整next或原before读回证明，不以replace返回值猜成功。零写失败可重试；写后抛错但完整next可证则成功一次；读回缺失保持owner，部分不明保reload锁。技术终止在未写时不依赖内容/world，写过后只在能证明before或next时释放，不再执行学习/扣量；真实强退回最后完整存档。换档/新游戏使旧代全部无效，旧finally/答案不清新owner。
