# D2c：BGM 播放端口、引子记忆与 MZ 适配器

本批继承纯六入口选曲 `47a84e2`，只提供后继 Scene/战前包装可调用的内部端口。`battle-music.ts` 无 Node/DOM/计时器，`battle-music-mz.ts` 集中 MZ 音频与文件访问。没有向公共 SDK 加出口，没有把它安装到 `PS_BattleFlow` 或事件命令，运行插件仍与基线相同。不能把本批无头受控播放器测试写成正式 Scene 播放、真实解码、实机发声或完整 WP15/16 已接受。

依据只读正式 WP24 §5.4/PT58–62、WP15 §6.1–6.2 与 WP16 §1/§7.1。新接口是宿主请求层，不移植参考实现；不是通用音频平台或原 247/248 可变记忆 API。

`battleMusicConfig` 在调用方开战冻结阶段复制显式作者 map/global/presets，不推导5.5地形。空预置忽略；原始预置字符串先解析音量/音高，记录保留参数，三个槽各自独立。普通字符串播放使用100/100，`Theme:70:120` 的逻辑文件名为 Theme；一般播放不把嵌入参数当显式覆盖。后继从公开 TrainerBattleProjection.presentation 传只读字段，不能读应用私有事实或 Showdown 内部状态。当前端口接收这些字段，但实际公开查询与 op 冻结尚未接线。

`BattleMusicPlayback` 接收带 op/generation 所有权的端口，支持独立 intro、一次开战 BGM、一次正常 return。PT58–62：空引子无副作用；已有 R/r 保留并不取消 Q；无备忘时优先取消待播 Q 并记 Q/0，否则记当前 A/位置，仅位置查询异常取0。记忆/取消先于播放器请求，媒体失败不回滚；只读诊断给出请求与原因。普通 Battle BGM 在恢复时同样保留原位置。外部正常包装清备忘/下一战预置，不能在选曲器或本端口悄悄消费它们。异常、取消走明确 release，不擅自恢复旧世界曲目。

MZ 适配器只准备当前 MZ audioFileExt 对应的原生文件（含其加密后缀）；不是六扩展名搜索/格式兼容已完成。路径限定 audio/bgm，拒绝路径穿越/链接逃逸，真实访问错误是 failed，普通不存在是 missing。缺资源仍有逻辑请求诊断，且不停止已有宿主音乐。预加载缓冲无 autoplay，独立5秒单调截止；每个解码回调、定时器和发布前重验所有权。准备完成才以 MZ 音乐音量更新并交付 BGM 通道，兼容现有 ME 暂停门，不停止 ME/BGS/SE 或关闭共享 WebAudio。

此适配器唯一访问 MZ 的 `_bgmBuffer`/`_currentBgm`；缓冲和登记对象同时匹配才释放通道。同缓冲被新登记复用、其他曲目接管、stop 回调重入都不能覆盖或销毁继任者。正常恢复请求仍在操作所有权内解码，成功后明确把返回音乐移交世界；Scene 退出不应随后 cancel 已移交的世界音乐。未完成解码仍属旧操作，替换/取消必须退休，迟到结果不得播放。后继需由实际 op 生命周期调用并验证，而不能仅靠 `PSFlow.running` 或 Scene 存活判回程所有权。默认 BGM 覆盖通过适配器显式配置，逻辑登记与实际曲目分列，MZ 音乐选项在交付时缩放。

验收是受控端口/文件/定时器与真实 TS 编译路径：引子五分支、正常/空回程、缺失与访问失败、解码错误和截止、后继接管、取消和重入、独立资源释放；反向变异实际修改源码副本。首次定向测试发现失效所有权时新 lease 被重复 release，已修复并保留失败日志。临时资源全在操作系统临时目录，不写工程 img/audio 或改宿主配置。

后继必需：把作者配置和公开投影冻结进真实 host op；将 intro 放在事件/战前阶段而非同帧被开战 BGM 覆盖；Scene 开始播放与正常结束/接收/进化继续流程的回程所有者；state replacement/abort/reentrant 开战取消；实际音乐资源/播放/选项/恢复验证。胜利/捕获 ME 和3.5秒等待、BGS完整暂停恢复、待播cue调度器、默认覆盖下停止/淡出、四预置清理、黑屏/0.4秒世界回褪仍后继，不以本批关闭。新 NW/精确 CI/实体听感/Windows、完整 D2/E/P4、GC WARN 和旧 U51 UNKNOWN 保持未关。
