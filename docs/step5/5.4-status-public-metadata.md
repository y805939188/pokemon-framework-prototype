# 5.4 状态框公开外观标记接线

本批独立继承已接受1943edb，不依赖待审的a1f2b01共享摘要。依据冻结D-2及WP67-A §9.2，把性别、闪光和对方已拥有标记接入现有真实状态窗口；不修改战斗规则、Session／v1协议、库存或持久提交。

外观值只消费已排队的公开switch／drag／replace／detailschange详情，按既有显示轨道绘入时才成为shown状态；-formechange仅更新已知外观的公开物种。副本分离，不能通过读取DTO修改后续帧。成员的私有gender／shiny／物种不能补足缺失来源；公开详情没有M/F时是无性别，未列shiny是已知非闪光。

当前宿主只在公开事件成员ID与本侧当前active真实ID相符时确认绑定。别名不同（如Illusion尚未解除）、多次派出后的非当前成员、来源缺失时，外观／标记明确未知；对方未知名字显示本地化Unknown。这是一种保守降级，不声称实现完整伪装外观来源。正常实际Illusion解除的replace重新确认真实ID，以已显示HP比例继续，不从私有属性预告真身。完整别名来源、Transform／更多形态细节及其它图片消费者继续OPEN，不能用本批签收完整状态框。

确认来源后，Scene把公开战斗物种经已有speciesKey映射成持久内容物种ID，再查询玩家owned记录；仅seen不算拥有。形态按内容映射归基础物种；缺内容映射是未知。己方从不显示owned标记。男女分别用蓝／红符号，闪光用星号，对方拥有用本地化短文本；恢复原字体色与透明度，默认可替换效果不追求美术保真。

代码／编译Scene测试覆盖中英真实作者训练家性别和闪光、内容ID的owned与seen区分、正常换人清旧徽标、真实Illusion未知→解除、私有记录改动不影响公开显示、DTO隔离与owner退休。纯播放控制验证队列未播放时不提前发布、性别未知／无性别及来源失效。Window／输入／绘制／时钟受控，不等于NW／实际字体像素／实体输入。没有新APP、实机或性能测量。

本批不包含共享摘要，未来组合时仅需核对PS_BattleFlow不同区域和源码hashguard；不会因本批通过关闭待审摘要、完整D2/E/5.4/P4、GC WARN／U51 UNKNOWN或R13低优先缺口。依赖按只读约定复用；只为生成物使用独立必要副本，不删除原证据，不合main或更新总进度网页。
