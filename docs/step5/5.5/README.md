## 兼容与证据边界

- 5.4 旧事件空白天气仍是 none；显式 none 覆盖世界，新入口及显式 inherit 才使用锁存世界事实。weather／terrain／environment 分别解析，非法值拒绝。
- 黄昏球读真实时段／洞穴业务事实，诱饵球读实际钓鱼来源；视觉昼夜开关及 battleTime 不替代这些事实。
- 不新增独立 Fly 解锁集合；不引入病毒链、Headbutt／Dive／Waterfall，也不借归档扩大地图／伙伴范围。
- r5 报告的四项静态推断仍未复现：Fly “该点地图”解释为三元组目的地图；恢复状态早于黑暗显示规则；落位计数看到新图模式；自动保存看到已释放操作。
- **5.4 战败回程后的实际自动保存仍未核实**；r4 §3.6 的确定性描述已被 r5 §3.5／§7 限定，不能据此声称回退或无回退。
- `APPROVE_FOR_IMPLEMENTATION` 是方案层面的历史结论。B–G、完整 5.5、实机、性能、跨平台、原版等价和人工输入／听感／手感均不由本次文档归档签收。
