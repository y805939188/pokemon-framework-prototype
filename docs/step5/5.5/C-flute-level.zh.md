# C 黑白笛：等级模式与原频率模式

本项目选定：`FLUTES_CHANGE_WILD_ENCOUNTER_LEVELS=true` 时黑笛启用 `higherWildLevel`，白笛启用 `lowerWildLevel`；这是已授权的项目设计映射，不宣称已证明原版逐色等价。道具使用和快捷查询本身不抽取等级或消耗生成随机。随后遭遇选择仍使用原等级消费者：基础等级→适用首队员特性→`random(4)+1` 的笛子修正，在1/100边界也保留该次抽样。两等级旗同时 true 时，原 lower 分支优先，且只抽一次修正。

设置为 false 时，黑笛维持降低遭遇频率（概率÷2、最少步数×2），白笛维持提高遭遇频率（概率×1.5、最少步数÷2），原 lower 优先不变。每次使用只把对应的一个局部旗设为 true，不清除其余三旗；同色重用、反色重用、运行时切换模式均沿此最小写集。跨图进入与读档/新游戏的状态失效按原局部生命周期清理；同地图 transfer 保持原 unchanged 早退与局部旗，不新增持久字段。

实际背包可以使用与登记这类道具，回到地图后快捷菜单读取真实登记列表。WP27 的公开登记 API 仍允许登记合法但未持有的物品，未知物品登记无操作；实际背包只提供已有行，快捷执行仍要求库存和处理器。已登记物品在处理器丢失时仍可取消登记。既有 ItemCatalog `effect.family='flute'` 与已校验 `parameters.color` 决定作用，不按特定 ItemID 猜颜色。原黑白笛不消耗；作者可定义自有 ID 与显式 consumable，道具库存与局部效果经原 owned atomic 提交尾部一并处理。票据、owner、generation、Content、取消和重复提交守卫保持。
