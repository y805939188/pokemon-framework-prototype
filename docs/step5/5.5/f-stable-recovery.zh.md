# F：回程失败后的稳定恢复

当一次全灭已结算、`world.pendingReturn` 仍有未完成回程时，当前地图进入恢复模式：暂停新移动、地图事件、队伍/盒子管理、战斗、道具和场外动作。回程完成并清除检查点后，原有操作立即恢复。

这是异常资源失败的恢复限制。它保留原目的地、已完成阶段及治疗/统计凭证，避免异常期间再次产生未结算全灭；不引入新存档协议或义务队列。默认关闭野外毒伤的正常游戏及无回程检查点的地图不受该门影响。

恢复模式提供受限原生菜单：重试回程、保存和返回标题。只有稳定失败且没有原有运行锁时才临时允许打开此菜单；原保存开关继续生效，普通菜单命令保持禁用。该例外不解除一般剧情的菜单/存档限制。

“重试回程”先正常返回地图，等待真正当前地图更新和原生来源就绪，再走原有私有重试路由。UI 不生成 owner、source、ready 回执或转移权限。失败不会自动无限重试；检查点仍保留，稳定状态仍可按原规则保存。目的地资源永久损坏时，当前地图业务保持受限，需要修复资源、读取其它存档或返回标题。

门由现有 blackout 检查点派生，与运行中的 active/saveBlocked/encounterBlocked 分离。原 F owner 的完成、到达、保存回执和正式读档恢复继续工作。E3 的普通转移检查点不触发本恢复模式。

正式旧 schema11 存档中的合法回程检查点读取后派生相同恢复模式，不需要迁移。对于已经由旧异常产生的第二次未结算全灭存档，不根据 HP 或猜测历史回填治疗/统计；保留原件并说明边界。
