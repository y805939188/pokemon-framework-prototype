# 5.4 RPG 持物的原生战斗身份补齐

基线 `033665b42ccbce89e88822df14195199477184c9`。本批是 FR55 三种已准入 RPG 持物的身份适配，不改变固定 Showdown 的 Fling 算法、伤害、概率、消耗/转移/回收流程或成长/奖金事务。未合并 main。

## 判定与来源

固定 Showdown `7244fe8e28fa8bc4d0809ae30d183c608b62bb2b` / Gen 8 不含 Lucky Egg、Amulet Coin、Luck Incense 的原生道具记录；框架却已正式准入它们，并有成长或奖金消费者。普通 Fling 因缺少 Item.fling 而失败，是 RPG 身份适配缺口，不应把“竞技引擎省略 RPG 道具”误当成这些道具不可投掷的游戏规则。

正式净化规格库提交 `5c9805de2331f75565891851d4d7b2bc97acad94`，`combat-requirements/wp47-b-control-items-coverage-data.md`，SHA256 `3a4b189f23a82dae95b0750ca6967d168ee85afe6e27594e00e6d183f4a63827`：第 72 行 Luck Incense 为 10；第 75 行 Lucky Egg、Amulet Coin 为 30。公开 [Lucky Egg](https://bulbapedia.bulbagarden.net/wiki/Lucky_Egg)、[Amulet Coin](https://bulbapedia.bulbagarden.net/wiki/Amulet_Coin)、[Luck Incense](https://bulbapedia.bulbagarden.net/wiki/Luck_Incense) 页面亦佐证这些威力；实现不读取原版 Ruby。

## 最小适配

- 一份只读 RPG 身份表同时供准入与战斗适配使用，精确 canonical ID 准入及作者禁持限制不变。
- 仅 RPG format 经其已有 `battle` 扩展点包装 `setPlayer`，在建造 Pokemon 及原生恢复引用解码之前，给本场建立独立 Dex/items 视图。补充对象使用固定引擎自己的 `Item` 类且深冻结；快照不保存函数，原生恢复构造自然重建局部视图。
- 仅补原生不存在的三条身份及 Fling 威力。原生已存在记录始终优先；共享 Dex、Items 数据、缓存、上游源码、依赖版本、协议和存档 schema 均不修改。列表视图按需构造，不给无关战斗强制枚举原生物品。
- 原生 Fling 继续拥有抑制门、PP、实际伤害和消费；HeldTracker、成长当前/还原记录、初始持有者入场奖金标记、原子提交和重放防重全部沿现有路径。

Flower Sweet 原生已存在、固定威力为 0；本批明确保留其 0 伤害但消费的结果，不用该适配覆盖已有 Showdown 规则，也不声称整个 Fling 道具表、整个 FR55 或完整 5.4 已关闭。
