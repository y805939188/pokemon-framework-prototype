## 验证方式（每个新规则模块）

| 模块 | 方式 | Ruby 运行证据 |
|---|---|---|
| 个体生成 `member-factory` | 规格驱动 + 不变量 | 无 |
| 领取 `grants`、容量 `limits` | 不变量/边界 | 无 |
| 治疗 `heal` | 规格驱动 + 幂等 | 无 |
| 遭遇抽选 `encounter` | 规格驱动 + 分布 | 无 |
| 战败结算 `defeat` | 规格驱动 + 幂等 | 无 |
| schema 3 迁移 | 迁移链与拒绝 | 不适用 |
| 成长/经验（沿用，未改） | 第三步 Ruby 对照 3504 例 | **有** |
| 宿主行为 | 真实 MZ 集成 | 不适用 |

“规格驱动”是从规格文本推导的期望，不是原版运行结果。本步没有读取或运行原版 Ruby，也没有需要请求隔离观察端补证据的歧义。
