产品固定 64c1cea；这一后继只加入测试驱动、静态冻结及合成控制，不修改产品规则、公开 SDK 或此前原生包。先独立静态审查及精确 CI，再由独立审查者绑定既有监督器、核实时宿主空闲和执行准入。作者不运行 NW。

一进程、两逻辑组、按顺序三案，150 秒总上界，首败停止、余项 NOT_RUN、无自动重跑：

每案在终局队列结束且菜单就绪时，读取实际生产 Window 的 `_lines`、当前语言、训练家身份、Continue 文本和完整状态 hash；同步 `Bitmap.snap` 获取显示窗口及临时隐藏窗口的像素差，保存显示 PNG/hash、frame/time、状态及安装数。审查者须检查三张实际 PNG 的可见文本；像素差本身不是 OCR 或字体正确性的证明。快照在确认之前，不能用动画结束后无关截图替代。

安装观察器仅暂包裹当前自有 Game_System 的 `_psGame` 属性，保留原值及真实写回，记录每次 setter 的前后状态 hash/余额，不替换 App/Session/StatePort 或结算算法；退出时恢复原属性形状并保留最新值。实际确认调用现有生产菜单 handler；不声称物理按键覆盖。旧 handler 重复调用后完整状态、收据及安装数保持不变。

复用已资格四个 Ogg/WAV 原字节及现有冷 Title/已启动 Map 门、Gen8 App、编译插件和打包流程。新 INPUT 绑定三产品插件、两个引擎运行包、测试插件、计划、媒体、干净提交、独立存档路径和完整 APP 指纹。不得借用旧 Ball5/ME15/音乐17/胜利6 的实机分母。

无头合成测试完整三链、缺像素停止、提前同值安装拒绝、报告身份和实际负载身份拒绝；它直接放置受控 Title，并不运行真实 Boot 或 NW，合成图像/音频只用于可达性验证，NOT_SELF_QUALIFIED。真实原生运行须补 PID/退出/自有组、fatal/清理首因及 APP 全文件/链接前后核同；只管理自有资源及隔离测试档。

完整逐句消息/pause/brief平台、训练家滑入/开场、物理输入/听感、Windows、新P4、真实NW信号、GC无泄漏与完整D2/E/5.4均不在本配方接受范围。历史 FAIL/WARN/U51 UNKNOWN 保留。
